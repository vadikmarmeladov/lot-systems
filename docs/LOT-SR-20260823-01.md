## DECISIONS FLAGGED FOR S-2

```
1. FORM FACTOR DEVIATION: spec point 4 asks 4x4cm x 5mm. No COTS path
   exists to 5mm total Z-height with a camera + screen + wireless-charge
   coil + battery inside a stainless shell. This package specs Rev-A at
   42x42x11mm (buildable, quoted in BOM/roadmap) and names true 5mm as
   Rev-B (v2, battery-less, always-docked). Flagged rather than silently
   built to a different number. NEEDS S-2 SIGN-OFF before DVT schematic
   freeze (03-ROADMAP.md next actions).
2. RF THROUGH STEEL: stainless enclosure attenuates 2.4GHz Wi-Fi/BT.
   Mitigation (non-metal antenna window on one edge) specified but
   UNVERIFIED until EVT closed-shell RSSI test (Phase 1 gate).
3. SERVER-SIDE WORK NOT DONE: 05-SOFTWARE.md is a spec, not a shipped
   API. No routes were added to src/server/routes/api.ts, no Log
   whitelist entries added, no Devices Settings UI built. Production
   app code was intentionally left untouched this session — this was a
   planning session, and route/schema/auth changes to a live app are
   exactly the kind of action that should not land without explicit
   review, not something to slip in under a hardware-planning ask.
```
