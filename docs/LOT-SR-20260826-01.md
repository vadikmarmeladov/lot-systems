## CHECK A — BRIEF-VS-PHYSICS CONFLICTS SURFACED

```
1. 4x4cm x 5mm total height is not achievable with today's off-the-shelf
   display + camera + battery + Qi coil stack (11-16mm realistic minimum).
   Resolved in spec as Path A (buildable now, ~11-16mm) vs. Path B (5-7mm
   aspirational, requires custom-tooled thin electronics, a second much
   larger NRE program) — flagged for an explicit S-2 decision, not silently
   picked.
2. Two-piece STAINLESS STEEL body + WIRELESS (Qi) charger conflict directly
   — Qi cannot charge through solid metal, and a closed steel shell risks
   eddy-current heating next to the battery. Resolved in spec with two
   named options (non-metal charging-window insert, recommended; or drop
   to pogo-pin contact charging) — again flagged for a decision, not
   silently designed around.
3. Outward-facing camera on a nightstand device — no capture/privacy
   mechanism was specified in the brief. Spec adds a hardware-wired status
   LED (tied to the camera's power rail, not the MCU) as a non-negotiable,
   matching the transparency principle already written into the NODE-0
   spec ("an action that cannot be seen did not happen").
4. FCC Part 15 + UN38.3 battery certification is mandatory before a
   WiFi+camera+Li-ion consumer device can ship 100 units in the US — not
   in the original 19-point brief, added to the NRE table and the phase
   plan as a hard gate before the 100-unit PO.
```
