## WHAT WAS BUILT — USE CASE 02: THE NIGHT ANCHOR

```
Operator:     Legacy tier, 340+ day tenure, Root/Sacral-dominant chakra
              state, nightstand placement (60mm from bed edge)
Signal path:  SelfCareMoments "Ground" practice (22-day streak) →
              Assembly phase forming→assembled → THE SETTLE
              Rare-tier badge unlock (streak milestone) → THE LEAP
              downgraded by the edge-detection gate (Section 03) to
              THE HOP, because the nightstand geometry places the
              cube inside the 20mm safety threshold
New ground covered vs. USE CASE 01 (Desk Migration, daytime):
  - Nighttime / bedside context, not desk / daytime
  - Root/Sacral archetype, not Clarity Architect
  - Exercises THE SETTLE gesture (unused by USE CASE 01)
  - Exercises the Section 03 edge-detection safety gate under real
    tight-clearance conditions, not just as a stated spec requirement
  - Legacy tier operator, not Usership tier
```

The use case argues that the edge-detection gate is not a compliance
checkbox but the mechanism that makes a bedside-trust use case possible
at all — an operator will not keep an autonomously-actuating object
within arm's reach overnight unless it can be trusted to choose the
smaller, safer gesture on its own, silently, every time.
