  This repo already runs a real, continuously-shipping engine under a
  near-identical name: QIE (Quantum Intent Engine) — currently v108, 139
  patterns, 47 archetypes, 44 background jobs, 178+ dependency-graph nodes
  (see docs/assembly/2026-07-27_LOT-assembly_wiki-v82-fm-v107.md and
  docs/LOT-SR-20260727-02.md). QIE is a real, in-app behavioral pattern-
  detection system (journal/mood/energy/planner signals -> patterns ->
  archetypes) — not an LLM. "QI-46" (aspirational fine-tuned-LLM spec) and
  "QIE" (real, shipping pattern engine) are two different systems that will
  read as the same thing to anyone skimming commit history or docs. This
  needs an explicit naming decision from S-2 before any QI-46 code is
  written, or the two will collide in the wiki, the ledger, and subscriber-
  facing copy.

emotions... upload a person's being... calibrate the human with the
humanoid output" — has no buildable literal reading. Read against the spec

for S-2 to confirm or correct — it was not built, because Phase 0/1 gates
