## WHAT WAS BUILT

### `LotMail` model + migration

```
migrations/20260728120000_add-lot-mail.cjs
src/server/models/lot-mail.ts
```

Table `lot_mails`: `id`, `fromUserId`, `toUserId`, `body`, `read`, `createdAt`, `updatedAt`. No subject line, no threading, no attachments — simplest possible envelope. Indexed on `(toUserId, read, createdAt)` and `(fromUserId, createdAt)`.

### `/email` Log trigger

```
src/client/utils/logTriggers.ts   — new trigger: email-compose (✉️ ✉ 📧, /email, /mail)
src/client/components/Logs.tsx    — parses "/email to [Name] [message]", opens inline
                                     compose panel, POSTs via useSendLotMail
```

Command shape: `/email to Hitomi Hey, are we still on for Friday?` — recipient is matched
by first/last name (case-insensitive) against `User`. Compose panel shows To:, an editable
body, Send/Cancel. On success the panel collapses to a cockpit-style status line
(`MAIL: SENT → HITOMI`); on failure, the server's hint (e.g. "No operator named X in LOT
Community") surfaces the same way. `/system` help updated with the new command.

### Sync Mail tab

```
src/client/components/EmailInbox.tsx   — new: inbox list, expand-to-read, mark-read-on-open
src/client/components/Sync.tsx         — Chat | Mail tab strip, unread badge, SSE listener
```

Sync (LOT Chat) now has a two-tab strip: **Chat** (existing community chat, unchanged
behavior) and **Mail** (new inbox). Unread count shows on the Mail tab label. Opening a
message marks it read via `PUT /api/mail/:id/read`.

### Server API + real-time delivery

```
src/server/routes/api.ts
  POST /api/mail              — send (name lookup, self-send guard, 2000-char cap)
  GET  /api/mail/inbox        — last 50, sender names joined in
  GET  /api/mail/unread-count
  PUT  /api/mail/:id/read
  SSE case 'lot_mail'         — routed only to the intended recipient's /api/sync stream
```

Mail delivery reuses the existing `sync` EventEmitter / SSE infrastructure — no new
transport. A recipient who has Sync open sees the unread badge and inbox update live,
without a page refresh.

### Cohort integration (LOT Community)

```
src/client/components/ChatCatalystWidget.tsx  — "✉ Mail" button on cohort-match cards
```

The codebase has no "Cohort Dating" module by that name — the closest existing concept is
**Cohort Connect / Chat Catalyst**: behaviorally-similar-operator matches surfaced for
connection. Added a secondary "✉ Mail" action next to the existing connect button — clicking
it navigates to the Log tab and pre-fills `/email to [cohort match name] `, so a cohort
match can be emailed directly from the match card in one step.
