## DESIGN PRINCIPLES APPLIED — v30

### ASCII Symbol Language
- Vault/archive aesthetic: `╔`, `║`, `╗`, `═` (box-drawing characters for the "vault" feel)
- Time/motion: `←`, `→`, `►`, `◆` (directional markers for temporal flow)
- System-state: `●`, `○`, `·`, `∞` (binary/state indicators)
- Hybrid/compound: `╔·T·╗`, `●·P·●`, `·V·` (badge identity within containing structure)

### RPG Easter Egg Criteria
- Every badge has a **discovery trigger** (word, date, behavior, combination)
- Every badge has a **self-care resonance** (why it connects to the practice)
- Every badge has a **lore connection** to the wider LOT universe
- Secret bosses require **named knowledge** (must know Turing, Lovelace, Wells by name)
- The `lot_birthday` badge (Apr 7) is a system self-reference — the only badge where LOT acknowledges its own age

### Fun Easter Egg Design
- `golden_hour` → requires patience + 5 consecutive mornings near sunrise (30-day window)
- `time_capsule` → requires intentional past+future writing in one entry
- `lot_birthday` → LEGENDARY rarity on LOT's own founding date (surprise for long-term users)
- `wells_temporal` → just write "time machine" anywhere in a journal entry
- `lovelace_signal` → MYTHIC rarity; Ada Lovelace is the deepest unlock
