[D-001 rev A]  On hardware naming lineage: LOT® and COSMO® hardware tracks
               are father/son marks (LOT_ROBOTICS_COSMO.md) and must never
               collide on the same object name. CUBIQ™ (LOT®) is a
               notification body that moves — no screen, no camera, motion
               is its only language. COSMO® Computer is the physical-face
               object — screen, camera, button, LOT API connector. Confirmed
               twice: LOT-CUBIQ-QUANTUM-CUBE-v0.md Section 00 names the
               distinction in advance; LOT-COSMO-COMPUTER-v1.md Section 00
               (LOT-SR-20260805-02) builds the object that distinction was
               reserving space for. Any future physical-product document
               must state, in its own reading log, which of the two
               (or a stated v2.0 convergence, per LOT-COSMO-COMPUTER-v1.md
               Section 07) it extends.
