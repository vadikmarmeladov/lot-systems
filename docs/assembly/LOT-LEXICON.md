# LOT SYSTEMS — ASSEMBLY LEXICON
Evolving controlled vocabulary for the Benchmark session-report corpus.
A token is minted only after its concept has recurred in 3+ prior session
reports, or has been folded into doctrine twice (see
`docs/assembly/LOT-DOCTRINE.md` and the SELF-ASSEMBLY protocol). Until then a
concept stays as plain prose in reports. Tokens are never deleted — a
superseded token is marked `DEPRECATED -> <new token>` so old reports stay
legible.

Bootstrapped 2026-08-01 (LOT-SR-20260801-01): no prior LOT-LEXICON.md existed.
Per the self-assembly first-run rule, this file starts EMPTY rather than
seeded with invented vocabulary — an audit of the ~85 pre-existing
`docs/assembly/*.md` notes for organically recurring terms is future work,
not something to fabricate in this session. Candidate tokens surfaced by each
session are logged in that session's report; they graduate here once they
cross the minting threshold.
