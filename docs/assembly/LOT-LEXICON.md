# LOT SYSTEMS — ASSEMBLY LEXICON

Evolving controlled vocabulary for the `docs/assembly/` benchmark corpus.
A concept earns a token only after it has appeared in 3 or more prior
session reports in this corpus, OR has been folded into doctrine twice.
Until then it stays as plain words — see `docs/assembly/LOT-DOCTRINE.md`
and the self-assembly minting rule. Tokens are never deleted; a superseded
concept is marked `DEPRECATED -> <new token>` so old reports stay legible.
