### 5. Background Job 11 — `daily-source-diversity-pulse`

**Schedule:** 07:00 UTC daily (hour 7 added to interval guard)

**What it does:**

- For each user, counts distinct signal source types in their logs
- Computes system-wide average diversity score (unique sources / 11 possible)
- Reports: scanned · usersWithSignals · avgDiversityScore · uniqueSources · totalPossible

**Why:** Signal source diversity is a proxy for QOS completeness. A user with 1 source active has a narrow map. A user with 8+ sources is building the full QOS. The daily pulse tracks the system's depth coverage over time.
