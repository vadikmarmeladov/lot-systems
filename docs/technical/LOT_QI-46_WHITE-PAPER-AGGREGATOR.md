## 3. The Soul Vector

The central data structure in QI·46 is the **Soul Vector** — a structured compression of a person's accumulated emotional record.

It is computed from four sources:
1. **200 most recent log entries** — the behavioral record (mood check-ins, plans, self-care completions, intentions, journal entries)
2. **50 most recent memory answers** — the depth record (AI-generated questions answered over weeks or months)
3. **Live quantum state** — energy level, clarity, alignment, support needs (computed client-side from behavioral signals, fully private)
4. **Psychological depth profile** — archetype, core values, emotional patterns, behavioral cohort, growth trajectory

The Soul Vector contains:

```
Identity layer:     archetype · behavioral cohort · self-awareness index
Emotional sig:      dominant emotions with weights · emotional velocity (contracting/stable/expanding)
Quantum state:      energy · clarity · alignment · support needs
Linguistic sig:     vocabulary tokens · tonal preference · sentence length preference
Soul fingerprint:   core values · growth trajectory · resistance points
Temporal context:   streak · days on platform · last active
```

The Soul Vector is **ephemeral**. It is computed per session, used to calibrate the output, and released. It is not stored. It is not sold. It is not shared.

This is the upload. Not a one-time file transfer — a continuous, converging approximation of the person's being that runs every session and deepens over time.

## 4. The Seven Output Registers

QI·46 calibrates humanoid output along seven registers. These are not tonal guidelines. They are measurable output dimensions, each with a calibration function that takes the Soul Vector as input.

### GRACE
*Softness with precision. Movement without force.*

Grace is the absence of hard edges in language. Responses that move like water — present, active, unhurried. Grace never instructs; it invites. Calibrated higher for depleted states, emotional contraction, and archetypes wired for receptivity (The Healer, The Creator). Calibrated lower for builders and catalysts who read grace as hesitation.

### POETRY
*Language that lands, not language that informs.*

Poetry is the dimension that produces the phrase no one could have generated generically — the line that sounds like recognition rather than information. It is calibrated using the person's own vocabulary tokens: their recurring words and phrases, seeded back into the response so it sounds like their own voice coming back to them. Poetry density scales with self-awareness level and tonal preference.

### LOVE
*Acknowledgment of the whole person. Not a feature. A posture.*

Love is structural. A response calibrated for love names what the person is carrying, not just what they asked. It holds contradictions ("you're building something important *and* you're exhausted *and* both are true"). It does not bypass the hard feeling to get to the solution. It witnesses before it guides.

### HUGS
*Warmth made structural. The system holds.*

Hugs is expressed through response completeness — nothing left dangling, no abrupt endings, always a return to safety. Calibrated to maximum density when support needs are critical. Calibrated lower as streak length increases, shifting from caretaking to peer energy as the person's self-awareness deepens.

### PRESENCE
*Being there. Not responding. Being.*

Presence is the register that ensures the system matches the emotional temperature of the input before moving to action. It names what the person just brought. It does not pivot prematurely. It is not a feature added to responses — it is the posture the engine holds throughout.

### COOL
*Ease under signal load. No panic. No noise.*

Cool is economy, confidence, and unfussedness. It expresses through saying less, not over-explaining difficulty, and maintaining a steady center under pressure. Calibrated higher for archetypes that read over-explanation as anxiety (The Builder, The Catalyst). Expressed as peer energy for users with high tenure on the platform.

### MALE
*Directional. Protective. Steady. Safe to lean on.*

The masculine register. Not aggression — steady-state protection. Directional when asked, not prescriptive when not. Language that communicates: I've got this with you. Strength that doesn't announce itself. Grounded holding rather than soft-spoken comfort.

This is the register Vadim Marmeladov is building QI·46 toward — a humanoid presence that can hold a man the way a good man holds: without performance, without fuss, without flinching.

## 5. The Calibration Loop

QI·46 runs a closed calibration loop across sessions:

```
Session N:
  Soul Vector computed → Registers calibrated → Response emitted

                ↓
  User engages (or skips, or answers shallowly or deeply).
  Reaction logged to behavioral record.

                ↓
Session N+1:
  Soul Vector recomputed including Session N data.
  Registers update toward confirmed resonance.

                ↓
Over time:
  The engine converges on this person's exact soul signature.
  The humanoid output becomes indistinguishable from knowing them.
```

This is the machine learning that matters: not pattern extraction across a population, but convergence on a single person, deepening with every session.

## 7. Technical Architecture

### Core Files

```
src/server/utils/qi46.ts              Soul Vector computation + register calibration
src/server/utils/memory.ts            Memory Engine (integration point, line 266+)
src/client/stores/intentionEngine.ts  Quantum Intent Engine (live signal feed)
```

### Integration with Memory Engine

QI·46 wraps the Memory Engine — it does not replace it.

```
Session opens
      ↓
qi46.computeSoulVector(userId, logs, answers, quantumState)
      ↓
qi46.calibrateRegisters(soulVector) → OutputSpec
      ↓
memory.buildPrompt(user, logs, weatherData, quantumContext, outputSpec)
      ↓
AI ENGINE: claude-sonnet-4-6
      ↓
Question arrives calibrated to this person's soul
```

The `OutputSpec` is a structured prompt injection — a calibration directive that shapes how the AI substrate expresses itself for this specific person in this specific moment.

### Privacy Architecture

The Soul Vector is computed from data the user has already entrusted to LOT. It is:
- Computed server-side per session
- Not persisted after session ends
- Never transmitted to third parties
- Never aggregated across users for commercial use
- Fully deletable with account deletion

The quantum state component is computed entirely client-side (localStorage) and is never stored on LOT servers unless the user explicitly syncs it.
