back to a network-fetched TypeScript 6.0.2 instead of the pinned ^5.9.3,

flagged as deprecated, no ignoreDeprecations set for 6.0). This reproduced
identically on a clean stash of master — confirmed pre-existing and
environmental, not caused by this session's edits. Resolved by installing
the pinned toolchain locally; tsc --version confirmed 5.9.3 post-install.
Not fixed in tsconfig.server.json itself — the pin is correct, the
container just started with no node_modules. Flagging for the next
session in case a fresh container reproduces it.
