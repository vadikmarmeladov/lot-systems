## NAMING DECISION

```
The brief's device is NOT the "COSMO® Cube" the old ghost manifest entry
named. It has a screen and a camera and does not move; CUBIQ™ (docs/
corporate/LOT-CUBIQ-QUANTUM-CUBE-v0.md) is a 45mm cube with no screen that
DOES move (hop/jump/levitation roadmap). Naming it "COSMO® Cube" would
collide with CUBIQ™'s own explicit warning against exactly that collision
(CUBIQ doc, Section 00). This session names the new device COSMO® Terminal
— it is the closed-enclosure, commercial embodiment of the already-
existing "LOT Terminal — open-source platform for self-care hardware"
concept (docs/corporate/LOT-TERMINAL-VISION.md), which already ships the
brief's own worked example (a weather station reporting to lot-systems.com).
```
