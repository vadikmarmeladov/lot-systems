02 // THE CUBIQ™ — WHAT HAPPENS IN 5-11 MINUTES
--------------------------------------------------------------------------------

The CUBIQ™ is the name for a single complete session. The operator opens
the system, passes through the cubic, and leaves. The cubic has faces —
each face is a dimension of the operator's life rendered as a widget.

A session is not a task list. It is a structured encounter with yourself.

  MINUTE 0-1 — ARRIVAL
    The system reads the operator's context: time of day, weather, location,
    last session gap, current chakra state, energy level. The AI has already
    decided what to show. The Memory Engine has a question ready. The
    Self-Care module knows if the operator needs to breathe, release, ground,
    observe, or connect.

  MINUTE 1-3 — THE MEMORY QUESTION
    The AI asks one question. Not a survey. A question chosen from the
    operator's psychological depth profile, their medical history, their
    trauma-informed resilience protocol, their behavioral patterns. The
    question feels like it was written by someone who knows them. Because
    it was — by an AI that has read every signal they ever produced.

    The operator taps an answer. The button responds instantly (visual
    feedback first, signal recording deferred — Async Signal Recording
    doctrine). The answer feeds back into the Quantum Intent Engine,
    adjusting the operator's archetype, User Index, and pattern library.

  MINUTE 3-5 — THE SYSTEM GLANCE
    43 widgets are available to the paid operator. The system does not show
    all 43 — it shows what matters now:

    CORE WIDGETS (always visible)
      TimeWidget               Current time, day counter (Day 1017+)

      EmotionalCheckIn         Mood tracking with 12 emotional states
      SelfCareMoments          5 practices: Breathe · Release · Ground · Observe · Connect
      EnergyCapacitor          Real-time energy level visualization
      ChakraErgonomicsWidget   7-chakra state (Crown → Root)
      IntentionsWidget         Daily intentions with completion tracking
      PlannerWidget            Structured planning with goal integration

    INTELLIGENCE LAYER

      SystemPulseWidget          5-cycle pulse: metrics → activity → userload → cohort → community
      PatternInsightsWidget      Deep pattern analysis with confidence scores

    COMMUNITY LAYER

    QUANTUM LAYER

      CalendarWidget             Orthodox calendar integration

    The operator writes. Free-form text in the LOG. The 7-second debounced

      /prayer     — AI generates contextual scripture (saved to log)

      /night      — Dark mode

    The log entry is the operator's journal. But it is also a signal source
    for the QIE — word count, emotional tone, time of day, gap since last
    entry, all feed the pattern library.

  MINUTE 8-11 — THE CUBIC CLOSES
    The operator has checked in emotionally, answered a memory question,
