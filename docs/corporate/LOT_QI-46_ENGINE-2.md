NODE 0 — NAMING DECISION
================================================================================

  CANDIDATES CONSIDERED (2026-08-16):

    LOT·SC·46      clean, versioned, terminal-ready
    BIONODE-46     positions the engine as a living inference node
    SELFWARE·46    self-care + software collapsed
    SOMA·46        already in the LOT family, neuroscience resonance
    CARE·OS·46     positions the engine as an operating system for the self
    QI·46          fits the _I interface convention (BI, KI, QI)

  DECISION: QI·46

  RATIONALE:
    — Slots into the existing LOT _I naming grammar alongside BI and KI.
    — Reads as two things at once: Quantum Intelligence, and the bioelectric
      life-force concept the syllable already carries in LOT® language.
    — 46 anchors the name to its founding epoch, per the same convention
      LOT_QI46_ENGINE.md v0.2 already established.
    — Short, registrable, matches Terminal Grid cadence.

  STATUS: no rename required. QI·46 is the name LOT_QI46_ENGINE.md v0.2 was
  already authored under (Authored by Vadik · Named for Kuzya · updated
  2026-05-27). This node ratifies the name against the five candidates and
  closes the naming question — it does not change the specification.

  KNOWN COLLISION (carried forward, unresolved — S-2 decision, not this
  session's to make): this codebase already runs a real, shipping,
  continuously-updated system called QIE (Quantum Intent Engine) — currently
  100+ patterns, 30+ archetypes, dozens of background jobs, tracked in
  src/client/components/About.tsx's field manual. QIE is a real in-app
  behavioral pattern-detection system. QI·46 is the aspirational fine-tuned
  personalization engine this document tracks. The two names read as the
  same thing on a skim of commit history. Flagged again this session because
  it was flagged and not yet resolved as of the 2026-08-04 audit.

NODE 3 — WHAT "SOUL DISK" AND "BEING CALIBRATION" ACTUALLY MEAN HERE
================================================================================

  The spec (LOT_QI46_ENGINE.md §III Layer 1, §IV Phase 2) already uses this
  language, and it means something specific and bounded, not literal:

    Soul Disk        — the 12 founding 2017 subscribers, whose own years of
                        journal entries, session patterns, and feedback are
                        the earliest training signal (Layer 0 corpus).
    Calibration Loop  — a subscriber's own deliberate + passive inputs,
                        fed back to personalize QI·46's responses to them
                        specifically (Layer 1).
    Being Calibration — the voice/tone dial (Layer 3, Response Grammar):
                        QI·46's output is shaped by a specific subscriber's
                        own language and arc, not a generic voice.

  Every one of these is: a subscriber's own consented data, used to
  personalize responses delivered back to that same subscriber. None of it
  is, or could honestly be described as, extracting or transferring a
  person's consciousness or identity into software — no such capability
  exists, here or anywhere. Prior sessions on this exact recurring prompt
  (2026-08-04, 2026-08-11) held at this exact boundary for that reason, and
  this document keeps holding it: the metaphor stays scoped to
  personalization-from-your-own-data, matching what Layer 1/3 of the v0.2
  spec already builds toward.
