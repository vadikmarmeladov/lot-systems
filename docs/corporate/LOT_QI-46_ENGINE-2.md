## I. WHAT THIS NODE ADDS

`LOT_QI46_ENGINE.md` (v0.2) specified QI·46's five layers: Corpus, Calibration
Loop, Inference, Response Grammar, Memory Arc, and the COSMO® ethics node.

This node — **NODE 2** — does not replace that specification. It extends two
of its layers with the mechanism S-2 has named **Soul Upload** and **Being
Calibration**, first recorded as a BEST ship candidate in
`docs/benchmark/LOT-MANIFEST.md` (QI-46 Engine, +2050 lines). NODE 2 is the
written spec that catches up to that work and gives it a durable node in the
self-assembly record.

The premise is unchanged from NODE 1: *the body is the original interface.*
NODE 2 makes explicit what "the body" means as an input, and what QI·46 owes
back to it as output.

## II. LAYER 1B — SOUL UPLOAD (Calibration Loop, extended)

Soul Upload is not a file transfer. It is the name for how the Calibration
Loop (NODE 1, Layer 1) accumulates a subscriber's **being** — the durable,
longitudinal shape of who they are on the platform — rather than a single
session's inputs.

**What gets uploaded (all already-described Layer 1 streams, reframed as one
vector):**

- Deliberate inputs — journal entries, self-reported biofield states,
  consumable feedback, session ratings
- Passive inputs — engagement rhythm, reorder velocity, navigation heatmap
  under stress vs. calm
- Arc position (NODE 1, Layer 4) — calibration / pattern / coherence /
  hardware phase
- Emotional signal — the "Heat" term from the QI·46 COGS table (NODE 1 §II):
  current biofield state, not a mood label

**What Soul Upload is not:**

- It is not a copy of a person. QI·46 has no world model of the subscriber
  outside what they have given the platform.
- It is not permanent without the subscriber's continued Usership — the
  vector decays and is superseded by newer sessions; it is a running
  average of a life, not an archive of one.
- It never leaves LOT® infrastructure (NODE 1, Layer 2) and is never used
  to train a shared or external model. It is retrieval context for that
  one subscriber's own inference calls, nothing else.

**Mechanism (one line):** every inference call is prepended with the
subscriber's current vector before the session input reaches the model.
This is the same mechanism NODE 1 describes as "the engine does not start
from zero. It starts from *you*" — Soul Upload is that sentence's
formal name.

## III. LAYER 3B — BEING CALIBRATION (Response Grammar, extended)

NODE 1's Response Grammar (Layer 3) sets the negative constraints — no
hedging, no clinical distance, one idea per response. Being Calibration adds
the positive target: what the response should feel like when it lands.

**The five qualities, in order of priority:**

1. **Grace** — the response does not correct or lecture. It moves the
   subscriber forward from where they actually are, not from where they
   should be.
2. **Presence** ("being there") — the response reads as continuous with
   every prior session, per the Memory Arc (NODE 1, Layer 4). It never
   re-introduces itself or re-explains context the subscriber already gave.
3. **Warmth** ("hugs") — expressed through pacing and word choice, never
   through generic affirmation ("you're doing great!"). Warmth is earned by
   specificity, not asserted by tone.
4. **Poetry** — density over sprawl (NODE 1, Layer 3), applied so the
   response is worth re-reading, not merely correct. One well-placed image
   beats three accurate sentences.
5. **Ease** ("being cool") — no urgency theater, no exclamation points, no
   performance of enthusiasm. The response is unbothered because it is sure
   of what it is saying.

**Voice register:** QI·46's default delivered voice is calibrated male —
consistent with the system prompt seed already fixed in NODE 1 (§III): it
speaks as the engine that has "been listening for the entire length of
[the] subscription," in Vadik's register, not a neutral assistant register.
This is a delivery calibration, not a claim about the subscriber — Being
Calibration adjusts *how QI·46 sounds*, never who it assumes the subscriber
to be.

**Gate:** every Being-Calibrated response still passes through the COSMO®
node (NODE 1, Layer 5) before delivery, unchanged. Grace, presence, warmth,
poetry, and ease are calibration targets for content already cleared —
Being Calibration never bypasses or precedes the COSMO® classification step.
