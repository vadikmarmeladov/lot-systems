## WHAT CHANGED: v1.2.0 → v1.3.0

### New Systems
- **Architect Widget** — Executive self-assembly telemetry dashboard (paid users only). Shows LOT® Self-Assembly® brand, system phase, module telemetry, signal sources, phase distribution. Stable render via snapshot reads.
- **SPA Navigation** — Tab switches are now pure client-side routing. No page reloads. No `<a href>` tags. Instant.
- **QI·46 Engine Specification** — 1,078-line machine architecture document. 5-layer design, COSMO® ethics node, 4-phase assembly timeline.

### Critical Fixes
- **Theme integrity** — Log trigger detection no longer fires on component mount. Prayer/night triggers respect custom theme.
- **Trigger reliability** — `/synth`, `/radio`, `/prayer`, `/night`, `/qos`, `/assembly` all verified mount-safe.
- **Navigation speed** — Removed 200ms debounce, eliminated `<a>` browser navigation, pure `<button>` + `goTo()`.
- **Widget stability** — Architect widget no longer disappears. Removed `useStore(intentionEngine)` subscription that caused render cascades.
- **Log tab click area** — Fixed hidden click area that navigated to System tab.
