## LOT® Hardware Ecosystem

### LOT® Station — Weather + Air Quality
The LOT® weather station ships with the Usership kit. It reports:
- Temperature, humidity, pressure, UV index (feeds the existing Weather widget)
- **Air quality** (PM2.5, CO₂, VOCs) — new hardware-powered signal

**Air Quality Widget:**
When PM2.5 or CO₂ exceeds threshold, the widget surfaces a single, unobtrusive line:
> *Air quality: open a window for 30 minutes.*

No alarm. No red badge. A quiet recommendation in the same typeface as everything else. This is the Ambient AI™ principle applied to hardware signal.

### LOT® Brush — Connected Toothbrush
The LOT® connected toothbrush reports brushing events (duration, time of day, pressure) to the LOT® OS. This closes the self-care loop: the system knows whether the morning routine has been completed without the user logging it.

**Toothbrush Widget:**
The widget surfaces supply and timing reminders at the right moment:
> *Toothbrush: refill — new heads are coming July 3.*

First hardware shipment: replacement heads arriving **July 3, 2026**.

The brush data feeds the Self-Care module in the Self-Assembly engine. Brushing consistency becomes a coherence signal like any other. The module assembles silently.

## Design Principles for Ambient AI™

**Everything quantified. Nothing displayed unless it matters.**
The system measures continuously. It surfaces rarely. The gap between measurement and surfacing is where intelligence lives.

**The UX is the therapy.**
Scrolling LOT® is not idle browsing. It is a micro-ritual that activates the parasympathetic nervous system. Every interaction is an anchor. The user returns not because they need to — because they want to.

**Hardware is invisible data.**
The user does not manage sensors. They receive, at the right moment, a single sentence derived from what the sensors know. The complexity is structural; the surface is clean.

**Ambient means always present, never intrusive.**
LOT® Ambient AI™ does not alert. It does not badge. It does not send push notifications. It waits. When it speaks, the moment was earned.
