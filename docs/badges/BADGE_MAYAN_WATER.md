**Author:** Vadik Marmeladov, CEO & Founder, LOT Systems

## Core Concept: Mayan Dot-Bar System

Mayan numerals use:
- **Dot (•)** = 1
- **Bar (―)** = 5
- **Shell** = 0 (completion/cycle)

Combined with **water droplets**, **waves**, and **cosmic symbols** for an alien, fluid progression.

## Mayan Progression Philosophy

### Traditional Mayan Counting (Vertical):
```
20 = •     (one dot in second position)
     —     (one bar = 5 in first position)

13 = ••• (3 dots)
     —— (2 bars = 10)
```

### Applied to Badge Progression:
```
Day 1-6:    Building dots (∘)
Day 7:      First completion (∘∘ or ◦―)
Day 8-29:   Second cycle building
Day 30:     Major cycle (≈∘≈ or ◦―◦)
Day 100:    Mastery cycle (≋≋ or ―◦―)
```
