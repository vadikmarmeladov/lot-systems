## PHILOSOPHY

> *"Self-care is not a quest you complete. It is a world you build."*

LOT is an RPG and Arcade of self-care. Every check-in is a move. Every
streak is a power-up. Every answered memory question writes one more line
of your story. Badges are not trophies — they are transmissions from a
future self back to the present one.

The badge system speaks in symbols because symbols reach parts of us that
words cannot. A single `≋` carries more meaning than a paragraph. An
`○∿` says: *you began*.

```
∘ → ≈ → ≋           [ Water Path ]
├─ → ╞═╡ → ║·║       [ Architecture Path ]
· → ○ → ◉            [ Citizen Stage ]
```
