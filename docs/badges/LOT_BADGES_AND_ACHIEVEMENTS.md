## I. PHILOSOPHY

> "Self-care is not a quest you complete. It is a world you build."

LOT is an RPG and Arcade of self-care. Every check-in is a move. Every streak is a power-up. Every answered memory question writes one more line of your story. Badges are not trophies — they are transmissions from a future self back to the present one.

The badge system speaks in symbols because symbols reach parts of us that words cannot. A single `≋` carries more meaning than a paragraph. An `○∿` says: *you began*.

## II. THE DUAL BADGE SYSTEM

LOT offers two visual metaphors for growth. Players choose their language.

### A. WATER PATH  ∘ → ≈ → ≋

```
∘    Droplet    — Day 7    — First drops form
≈    Wave       — Day 30   — Waves begin to flow  
≋    Current    — Day 100  — Deep currents established
```

Water is patient. It does not force — it finds the path. Your practice, like water, shapes everything it touches.

### B. ARCHITECTURE PATH  ├─ → ╞═╡ → ║·║

```
├─   Foundation  — Day 7    — Foundation laid
╞═╡  Structure   — Day 30   — Structure rises
║·║  Architecture — Day 100 — Architecture complete
```

Architecture is intentional. Every block placed with care becomes load-bearing. Your practice builds something that holds.

## XII. BADGE UNLOCK NOTIFICATION DISPLAY

```
┌──────────────────────────────────────────────────┐
│                                                  │
│  Memory:                                         │
│                                                  │
│  ┌────────────────────────────────────────────┐  │
│  │                                            │  │

│  │                                            │  │
│  └────────────────────────────────────────────┘  │
│                                                  │
│                            [5 second fade]       │
└──────────────────────────────────────────────────┘
```

**Notification Timing:**
- Appears before the next memory question
- 5 second display with fade-out
- Queued in localStorage if multiple badges unlock simultaneously
