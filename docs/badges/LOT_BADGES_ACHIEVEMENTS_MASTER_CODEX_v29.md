## THEMATIC NOTE — THE BIO-TERMINAL v19

The Bio-Terminal marks the first explicitly neuroscientific vocabulary in the LOT badge system.

**Previous engines** drew from:
- External experience (ocean, space, narrative, radio)
- Digital/computing metaphors (terminal, arcade, quantum)
- Esoteric/symbolic registers (alchemy, oracle, spell)

**v19 draws from:**
- The biology of the self as lived system — cortisol, circadian, vagus, dopamine, REM
- Neuroscience as both vocabulary and self-care philosophy — the brain as rewritable, the body as intelligent
- The three Secret Bosses (Cajal, Kandel, Ramachandran) as the founders of the neuron-level view of selfhood

The word "neuroplasticity" is EPIC rarity — not because it is obscure, but because what it implies is. The brain can change. The self is not fixed. Every practice is an experiment in wiring.

"Homeostasis" was coined by Walter Cannon (1926) to describe the body's tendency toward equilibrium. It remains the most quietly radical concept in biology: the organism's default is *return to balance*. Self-care is not heroic correction. It is trust in the homeostatic drive.
