## DESIGN PHILOSOPHY — THE TIME LOOP

The time loop is the oldest self-improvement metaphor in digital culture. Every roguelike
run that ends in defeat is not failure — it is data. The journal is the save file that
makes learning possible across loops. Each check-in is a new run. Each streak is a
high score.

Key references woven into the badge design:
- **Groundhog Day (1993)** — Phil Connors runs the loop until compassion breaks it
- **Back to the Future (1985/1989)** — "Your future is whatever you make it"
- **Steins;Gate (2011)** — World lines, divergence, attractor fields, Operation Skuld
- **Hades (game, 2020)** — "There is no knowledge without risk. The only true failure is the failure to learn."
- **Nietzsche — Eternal Return** — Would you live this day again, forever?

### Word Turn Milestone: 300
With v25, the Word Turn badge count crosses 300 across 25 engines. This represents the
system's broadest vocabulary surface — 25 different entry points into the same
self-care practice, each speaking the language of a different reader.
