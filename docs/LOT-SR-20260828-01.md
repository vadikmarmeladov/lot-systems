## SCOPE DECISION

```
This session builds MONTH 1 ONLY: a real route rendering a real, static,
read-only ledger — the OPEN TAB. It does NOT implement:
  - Real recurring billing (Month 2)
  - Real roster/PII intake — shipping address, sizing (Month 2)
  - Real supplier contact or quote confirmation (Month 3)
  - Real physical fulfillment / dispatch (Month 3)

Reason: those are real-world financial and logistics actions (charging a
card monthly, collecting a subscriber's shipping address, placing supplier
orders, shipping physical goods) that must not be taken by an unattended
scheduled agent run. Month 1's own exit criteria — "a stranger can read
what LOT issues and on what terms, read-only, live" — is achievable safely
in full: it is pure front-end rendering of static content. Built to spec.
Months 2–3 need explicit operator sign-off before any code that moves real
money or real inventory ships live; the UPGRADE control in this build is
present but disabled, honestly labeled "INTAKE NOT YET OPEN," per the
doctrine rule "the ledger is the marketing — no layer between public and
manifest."
```
