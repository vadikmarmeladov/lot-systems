## DESIGN DECISIONS

### Terminal Aesthetic

Visual reference confirmed as **IBM 3270 / dot-matrix terminal** (dark ground).  
Implemented design tokens:

```
Background:    #1a1a1a  (terminal ground)
Bg alt row:    #1f1f1f
Bg inset:      #141414
Text dim:      #888888  (standard / labels)
Text mid:      #aaaaaa  (moderate emphasis)
Text bright:   #e0e0e0  (primary content)
Inverted bg:   #c8c8c8  (ON STRENGTH bar, DELIVERED badge)
Inverted fg:   #1a1a1a

Font:          ui-monospace → SF Mono → Menlo → Consolas → Liberation Mono
Weight:        400 (regular) for body; 700 for inverted/status cells
Letter-spacing: 0.05em
```

Section dividers use **repeated ASCII characters** clipped at container edge:
- `====...` — major section break (bright opacity)
- `----...` — minor / column header rule (dim opacity)

This matches the LOT-FM-001 source document rendering exactly.
