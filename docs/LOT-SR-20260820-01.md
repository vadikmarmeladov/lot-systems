Nineteen-item hardware brief converted into a locked v.1 plan: LOT® Pager,
product code LOT-PAGER-01, a two-piece 316L stainless steel puck (one
polished presence face, one matte face carrying a round display, an
OV2640 camera, and a laser-etched COPY button) charging on a separate
40x40x5mm silver-anodized aluminum plate. Full electronics BOM and 100-unit
landed-cost estimate (~$112/unit fully loaded, ~$66.55/unit BOM-only)
built against current DigiKey/Mouser/PCBWay street pricing. PCBWay
fabrication path specified in three stages (bare-board prototype → PCBA
prototype → 100-unit production run). Firmware and software architecture
split into their own documents per the brief's explicit instruction, both
built to reuse existing LOT platform infrastructure (`/api/logs`, the M2M
intake protocol, the Fastify backend) rather than proposing new systems. A
rendered PDF user manual ships alongside its Markdown source. No hardware
has been built — this is Phase 0 of the 5-phase roadmap recorded in the
main document; Phase 1 (breadboard proof) is the next actionable step and
is not started.
