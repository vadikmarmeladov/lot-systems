not author names (v30), not fictional concepts (v31), but the arc of transformation

happens to a person who changes. The call is real. The threshold is real. The ordeal
is real. The return is real.

The v32 Word Turn engine makes these stages self-care triggers. "Call heard" is not
a badge name. It is a recognition: this person wrote about being called to something.
The system heard it and named it back.
