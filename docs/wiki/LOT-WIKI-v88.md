```
         Checks signal_coherence_cascade + quantum_presence_field +
         identity_momentum_lock ALL present in prior day's events.

         Output: total_field_coherence (P150).
         Metadata: metaSeals: ['COHERENCE','PRESENCE','MOMENTUM']
                   convergenceLevel: 'ABSOLUTE'
```

### Job Design Principles

```
1. Sequential ordering — later jobs consume outputs from earlier jobs
2. Prior-day scan window — no real-time mutation
3. Guard flags — prevent double-fire within same UTC day
4. Idempotent — re-running a job on already-processed data is safe
5. Console observability — all jobs emit structured log events
```
