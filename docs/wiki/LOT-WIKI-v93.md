## 20. COCKPIT RULE

**The console is the cockpit. Every line is a gauge.**

The log event body is instrument readings only. No narration. No explanation. No prose. The block label (e.g. `DARCSEAL:`) names the event. The body contains only:
- Metric codes and values (tabular key-value)
- Status flags ([CONFIRMED / —] / [ACTIVE / INACTIVE])
- Arc labels (DAWN→DUSK→SEALED)
- Confidence scores (CONF: N%)

Any log event body that contains a sentence is non-compliant. The cockpit is not a letter. It is a dashboard. The operator reads it in a glance or not at all.
