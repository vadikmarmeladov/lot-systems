## 04 // DISCOVERY — three real defects in the existing /system and /story

```
D1  STALE EVENT FILTER (correctness bug, silent for the operator)
    /api/story (api.ts) filtered "recent entries" by
    l.event === 'log_entry' || l.event === 'journal'. POST /logs (api.ts
    L1563-1587) actually writes free-text journal entries with
    event: 'note' (the request-body override path is never used by the
    Log UI). Net effect: /story has never once included the operator's
    actual typed journal text in its prompt to Together AI — only moods
    and self-care Q&A slipped through. Fixed: filter now reads
    l.event === 'note', with a one-line comment pointing at the write
    path so the next session doesn't have to re-derive this.

D2  NO DAY/WEEK/MONTH/YEAR COMPRESSION
    /story existed only as a single fixed window (last 200 logs, no date
    bound). The S-2 brief is explicit: "creates a compressed story of
    your day/week/month/year... to further compress the loop... surface
    more intimate high and low peaks." That granularity did not exist.
    Fixed: /story now parses an optional period token — /story,
    /story week, /story month, /story year (default: day) — and the
    server bounds the Log query to that window (Op.gte on createdAt),
    scales how many entries/moods/self-care notes it pulls per period
    (5/8/10/14), and rewrites the system prompt to explicitly ask the
    model to surface real highs and lows of that window rather than
    flattening it into one mood.

D3  ORPHANED /sil TRIGGER
    logTriggers.ts declared a full 'sil-check' rule (keywords 'sil',
    'silence-check') with a doc-comment describing exactly what
    'silent-mode' (/silent) already renders — but no dispatch branch for
    it existed in Logs.tsx. An operator typing /sil saw nothing happen:
    a phantom command, directly contradicting "/system... all commands
    appear" (a command that appears in no help text and does nothing on
    invocation isn't really a command). Wired 'sil-check' to the same
    signal-silence readout as /silent, and added both /sil and the new
    /story period variants to the /system help screen so it is now a
    complete, accurate command registry.
```
