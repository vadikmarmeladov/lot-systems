## BUILD — /story period compression + Chronicler Arc

```
src/client/utils/logTriggers.ts
  Doc comment updated: story-mode now documents [day|week|month|year] args.

src/client/components/Logs.tsx
  story-mode dispatcher: parses optional trailing period token from the log
  text ("/story week", "/story month", "/story year"; "/story" / "/story day"
  / "/story today" all resolve to 'day'). Period is passed to submitStory().
  /system help block: added 3 lines documenting /story week|month|year.
  useStoryGeneration onSuccess: awards a period-matched "Chronicler" badge
  (chronicler_day/week/month/year) via awardBadge() — first successful /story
  at that period unlocks it, same pattern as every other Arcade badge in the
  file (client-side, localStorage-backed, toast on unlock).

src/client/queries.ts
  useStoryGeneration mutation: added `period` to the request body type and
  `period` to the typed response (server echoes back what it used).

src/client/utils/badges.ts
  +4 BadgeType variants + BADGES entries: chronicler_day (common),
  chronicler_week (uncommon), chronicler_month (rare), chronicler_year (epic) —
  filed under a new "Achievement RPG v23 — THE CHRONICLER ARC" section,
  category: achievement_rpg, matching the existing Story Arcs badge families.

src/server/routes/api.ts  (POST /api/story)
  Added `period` to the request body (default 'day', validated against the
  4-value enum server-side — client input is not trusted).
  PERIOD_WINDOW table: look-back hours (24 / 168 / 720 / 8760), DB entry
  fetch cap, prompt entry count, target word range, and Together AI max_tokens
  per period — wider periods see further back and get a longer output budget
  (512 → 900 tokens) so a year isn't squeezed into the same 200 words as a day.
  Log query: added `createdAt >= since` (Sequelize Op.gte) so a "week" story
  only ever sees the last 7 days of entries, not an unbounded top-200 slice.
  Prompt: system prompt now names the period explicitly and instructs the
  model to surface highs AND lows, not just an averaged tone — matches the
  S-2 brief's "surface more intimate high and low peaks."
  Response + generated_story Log.metadata now carry `period` for the record.
```
