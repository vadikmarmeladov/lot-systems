05a // FEATURE — LOT EMAIL
--------------------------------------------------------------------------------
DESIGN: reuse, not a new subsystem. "/email to [Name] [msg]" typed in a Log
entry is a new `email-compose` entry in logTriggers.ts (RULES table — keyword
"email", emoji ✉). NoteEditor's existing trigger-effect parses
`/\/email\s+to\s+(\S+)\s*([\s\S]*)/i`, matches the name (case-insensitive)
against the operator's own Cohort Connect matches (useCohorts — same data
CohortConnectWidget already renders), and posts a formatted message
("✉ EMAIL → NAME" + optional body) through the existing useCreateChatMessage
mutation — the identical POST /api/chat-messages call Sync.tsx's send button
already makes. The server emits sync 'chat_message' unchanged, so the email
appears in Sync live via the SSE listener Sync already runs. Log shows an
"✉ EMAIL:" confirmation block naming the recipient and, when the name matches
a cohort member, their match % — the LOT Community / Cohort tie-in the intake
asked for; unmatched names still send, annotated "not in cohort — broadcast."
/system help text updated with the new command.
ZERO new schema, table, model, or endpoint. Net +47/-1 lines across 2 files.
