[CRITICAL] S-01 — Unauthenticated diagnostic endpoints leak API key previews + trigger live AI calls
  Service:  src/server/routes/public-api.ts (registered at /api/public/)
  Details:  Five endpoints require no authentication:
              /api/public/verify-api-keys       — shows first 8 + last 4 chars of
                                                  ANTHROPIC, RESEND, OPENAI keys
              /api/public/verify-admin-config   — shows admin email addresses
              /api/public/debug-memory-engine   — confirms key presence + SDK init
              /api/public/test-ai-engines       — maps which AI engines are live
              /api/public/test-anthropic-key    — makes a LIVE Anthropic API call
                                                  (burns tokens for any HTTP client)
  Risk:     Key partial-exposure enables targeted brute-force attacks.
            Anyone can call /test-anthropic-key to exhaust token quota.
  Fix:      Add admin-only auth guard (check req.user?.isAdmin) to all five
            endpoints, or move them behind /admin-api/ prefix.
  Priority: CRITICAL — fix before next public traffic spike.

[HIGH] S-02 — axios 0.27.2 in production (0.x branch, known CVEs)
  Service:  package.json dependency
  Details:  axios@^0.27.2 is on the legacy 0.x branch. Multiple CVEs have been
            filed against 0.x (CSRF, SSRF via redirects, prototype pollution).
            axios 1.x has been stable since 2022.
  Fix:      Upgrade to axios@^1.7.x. Breaking changes are minimal (only affects
            raw config object shape for some edge cases).
  Priority: HIGH — upgrade at next engineering session.

[HIGH] S-03 — Hardcoded Claude model ID will silently degrade when model is retired
  Service:  src/server/utils/memory.ts:1052
            src/server/utils/ai-engines.ts:139
            src/server/routes/public-api.ts:706
  Details:  Three files hardcode 'claude-3-5-sonnet-20241022'. This model is two
            generations behind (Claude 4.x family is current). When Anthropic
            retires this model ID, all three call sites will return errors with
            no fallback or notification.
  Fix:      Centralise the model ID in a single constant (e.g.
            src/server/utils/memory/constants.ts):
              export const CLAUDE_MODEL = 'claude-sonnet-4-6'
            Reference CLAUDE_MODEL in all three call sites.
  Priority: HIGH — do at same session as @anthropic-ai/sdk upgrade.
