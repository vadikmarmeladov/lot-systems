APPENDIX B — STATUS API: DEGRADED TIER LOGIC

  BEFORE (binary):
    hasErrors → 'error' else 'ok'

  AFTER (3-tier):
    Critical checks: ['Database stack', 'Memory Engine']
    hasCriticalError → 'error'
    hasAnyError      → 'degraded'
    else             → 'ok'

  This prevents Engine stack, Admin, or Settings check failures from
  triggering a full 'error' banner when core data services are healthy.
