## SYSTEM SUMMARY

LOT® Mail is a minimalist in-app email system native to the LOT® Operating System. It integrates three existing pillars — **Log**, **Sync**, and **Cohort Dating** — into a unified communication layer without introducing external dependencies or breaking existing UX.

## ARCHITECTURE

### Signal Flow
```
LOG: User types /email to Hitomi
  ↓ [detectNewTriggers detects 'compose-email']
  ↓ [EmailComposePanel opens inline in NoteEditor]
  ↓ [Recipient lookup: POST /api/users/search]
  ↓ [User writes subject + body → POST /api/email]
  ↓ [Server creates EmailMessage record in DB]
  ↓ [Server emits SSE: email_message event]
  ↓ [Receiver's Sync tab shows new MAIL card]
  ↓ [Log records email_sent + email_received events]
```

### Cohort Integration
```
COHORT WIDGET → "Mail" button clicked
  ↓ [pendingEmailTo store set: { id, name }]
  ↓ [Navigate to Logs tab]
  ↓ [Primary NoteEditor reads pendingEmailTo]
  ↓ [EmailComposePanel auto-opens for recipient]
  ↓ [Same send pipeline as /email command]
```

## UX DESIGN DECISIONS

**LOT® style principles applied:**
- No modal — compose panel opens inline in the Log text area (same surface as the command)
- No navigation change when composing — stays in Log
- Military formatting: `MAIL [OUT]:` / `MAIL [IN]:` in log events
- Recipient lookup is silent / inline (no separate search page)
- Subject is optional field (body is required)
- Panel auto-closes after send, clears the `/email to [name]` command from log text
- Inbox section in Sync is minimal: author name + subject + body excerpt + time

**Command syntax:**
```
/email to Hitomi        — triggers compose for "Hitomi"
/email to Hitomi S.     — full name lookup
✉️                      — same trigger via emoji
📧                      — same trigger via emoji
```

## INTEGRATIONS

### LOT Chat (Sync)
- New `email_message` SSE event appears in Sync tab inbox section
- Inbox shows above community chat messages
- Receiver sees sender name, subject, body, timestamp
- Cache invalidated on Sync mount

### Cohort Dating (CohortConnectWidget)
- "Mail" button added to each expanded cohort match
- Click sets `pendingEmailTo` store → navigates to Logs tab
- Primary NoteEditor picks up store value and auto-opens EmailComposePanel
- Records `cohort_email_initiated` signal for QIE

### LOT Community
- Recipient lookup uses `/api/users/search` (case-insensitive first/last name prefix match)
- Returns up to 10 matches
- EmailComposePanel resolves display name from API
