05 // IMPLEMENTATION
--------------------------------------------------------------------------------

FOUNDATION BUG FIXED (found while wiring `joinedAt`, not something guessed at
in the brainstorm): `MonthlyPulseWidget.tsx` has computed `monthsSinceJoined`
from `user.joinedAt` since it shipped, but `/me`'s `useProfileView()`
(`src/server/models/user.ts`) never included `joinedAt` in its `fp.pick([...])`
list, and the client `UserProfile` type didn't declare the field either. The
widget's month-1-through-12 messages have been silently dead in production
the entire time — `monthNumber` always resolved to 0. Fixed: added `joinedAt`
to both `UserProfile` (shared/types/index.ts) and the pick list
(server/models/user.ts). `joinedAt` is set to `new Date()` at real signup
(`auth.ts:239`), so existing accounts already carry an accurate value — this
also, as a side effect, revives MonthlyPulseWidget for the first time.

NEW: src/client/utils/freeTierReveal.ts — `getDaysSinceJoined()` /
`getMonthsSinceJoined()` (missing `joinedAt` reads as fully revealed, so
legacy/existing free accounts never regress to a bare-name state — they
compute a large tenure and see the whole arc immediately), plus the
`FREE_REVEAL_DAY` and `TEASE_SCHEDULE` constants encoding the spec above.

NEW: src/client/components/LockedTease.tsx — the grayed/blurred teaser
wrapper. Takes optional real `blurred` content (rendered with a CSS blur +
reduced opacity) plus a `teaseText` caption and a `brand.lot-systems.com` CTA.
Recipe and Calendar render with no `blurred` prop (plain locked card) since
there's no per-widget QIE signal to show for them; the other six use real
computed data.

IMPORTANT FINDING FROM THIS SESSION'S EARLIER SCAN, now load-bearing:
SR-20260727-01 found that `recordSignal()`/`intentionEngine` never gate on
subscription tier — every account, paid or not, has been accumulating real
QIE signals since day one. That's what makes the tease *real* instead of a
mockup: QuantumState shows the account's actual `getUserState()` energy/
clarity/alignment (reusing the existing render-isolation-safe `quantumState`
state already in System.tsx); Awareness shows the real `selfAwarenessLevel`
from `useProfile()`; Patterns shows the real `recognizedPatterns.length` from
the `intentionEngine` store; Chakra shows the real weakest-chakra charge from
the `chakraErgonomics` store; Self-Assembly shows the real `$assemblyProgress`
percentage. AI Feedback and Quantum Sign ship as copy-only teases (no natural
single blurrable stat for either).

MODIFIED: src/client/components/System.tsx (non-paid branch only — the paid
layout and `isPaidAccount` gate are untouched, so nothing changes for
existing Usership/R&D accounts):
- Header (name + week/date) and Team tags now always render at day 0.
- Time(+weather)/Memory/Community/MicroGame/month-1-chrome+Subscribe gated
  behind `FREE_REVEAL_DAY` thresholds instead of rendering unconditionally.
- The 9-item tease stack renders after the functional ceiling, gated by
  `TEASE_SCHEDULE` months.
- The requested footnote added, unconditional (not part of the staged
  reveal): "Demo: LOT® AI is available now, $99/month at

DOC: docs/technical/WIDGETS.md — new "Free-Tier UI Reveal" section
