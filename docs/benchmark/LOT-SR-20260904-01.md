05 // WHAT WAS BUILT
--------------------------------------------------------------------------------
TIME-OF-DAY   CalendarEntry gained an optional `time` (HH:mm) field, entered
              via a native time input beside the text field. Entries now
              sort date-then-time; untimed (all-day) entries sort first.
              This is the literal "time tracking" ask — a schedule entry can
              now anchor to a moment, not just a day.

COUNTDOWN     Upcoming entries show a live "(in 3 hours)" / "(overdue)" label
              via dayjs().fromNow() — accurate to the minute via a 60s
              re-render tick. No invented notation; reuses the app's
              existing relativeTime plugin.

CANCEL        Log is append-only in this codebase (no delete route is used
              anywhere for user content) — so removing an entry now writes a
              `calendar_entry_removed` tombstone log referencing the
              original log id via metadata.removedLogId. CalendarWidget,
              the alert checker, and Logs.tsx all filter live entries
              through this same removed-id set. First delete/cancel
              capability the widget has had.

ALERT TOAST   New CalendarAlertToast.tsx (mounted in System.tsx next to
              EvolutionMilestoneToast, mirrors its localStorage-dedupe +
              visibility-gated-interval pattern). Polls the already-cached
              /api/logs data every 30s; when a timed entry's moment arrives
              (0-30 min window, so a closed tab still catches recent misses
              without back-alerting stale history), it shows a terse
              uppercase "SCHEDULE ALERT // HH:MM" banner top-right for 8s,
              writes a permanent `calendar_alert` log entry, and feeds
              recordCalendarSignal('alert', date) into the QIE.

LOG HANDLERS  Logs.tsx: 2 new military event handlers — CAL-ALERT:
              (entryType + time) and CAL-CANCEL: (cancelled entry's date).
              CAL: (existing calendar_entry handler) now also prints time
              when present. Field archive military-format coverage extended,
              no prose, no gradients.
