## KEY DECISIONS

1. **ESP32-S3 over nRF52840** — WiFi native, camera interface, USB OTG, strong
   Arduino + IDF ecosystem. Power penalty acceptable for notification device.

2. **1.0" SSD1351 OLED over e-ink** — Fast refresh for real-time notifications.
   E-ink considered for v2 ultra-low-power variant.

3. **5mm → 8mm thickness for v1** — True 5mm is achievable in v2 after
   component refinement. v1 targets 8mm, which is thinner than AirPods case.

4. **PCBWay one-stop** — PCB fab + SMT + CNC stainless steel + packaging.
   Single vendor reduces coordination overhead for 100-unit prototype run.

5. **WebSocket over polling** — Real-time notification delivery. Device
   maintains persistent connection during active hours, deep-sleep during idle.

6. **LOT API device token** — Devices provisioned with unique JWT token at
   enrollment. No user credentials stored on hardware.
