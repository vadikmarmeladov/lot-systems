ACTION TAKEN:    Health audit → 4 defects found → all fixed

ROOT CAUSES FOUND:
  1. checkWeatherAPI() bundled three unrelated things (weather API, React
     bundle existence, Node.js version) under one misleading "Engine stack"
     check — made status page inaccurate and unusable for incident triage.
     Fix: split into checkWeatherAPI() → 'Weather API' and new
     checkClientBundle() → 'Client bundle'. Total checks: 8 → 9.

  2. performHealthChecks() returned only 'ok' | 'error', never 'degraded'.
     The 'degraded' path in both the API interface and the UI was dead code —
     could never be triggered. Fix: define CRITICAL_CHECK_NAMES (Database
     stack, Authentication engine, Systems, Client bundle); non-critical
     failures produce 'degraded', critical failures produce 'error'.

  3. Five diagnostic endpoints (verify-admin-config, verify-api-keys,
     debug-memory-engine, test-ai-engines, test-anthropic-key) were publicly
     accessible with no authentication — exposing admin email list, masked
     API keys, and internal AI engine architecture to any unauthenticated
     request. Fix: added `req.user?.isAdmin()` guard at each endpoint head.
     This exploits the global session hook already populating req.user on
     all routes; these endpoints now return 401 if not admin.

  4. StatusPage visual quality below standard for a TOP designer site:
     — Status was shown with plain ✓/✕ ASCII text
     — ok = black, error = black/60 (no semantic color)
     — 'degraded' overall state had no distinct visual treatment
     — Check rows had no structure or hierarchy
     Fix: refactored StatusPage to use colored status dots (bg-green /
     bg-red / bg-acc/30) from the LOT design system. Component list is now
     a clean row-per-check layout with inline response times. Overall banner
     uses text-green / text-yellow-darker / text-red per severity.
     Memory Engine section promoted from flat Block list to its own bordered
     section with status dots on "Next prompt" indicator.

ROUTED TO:       src/client/components/ + src/server/routes/
