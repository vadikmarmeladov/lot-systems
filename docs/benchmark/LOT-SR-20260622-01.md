/PRAYER PERSISTENCE FIX (Logs.tsx)

  NoteEditor remounts when autosave triggers refetchLogs → new empty log
  created → key changes → component remounts → state destroyed.
  Fix: onSuccess callback now appends scripture text to log value with
  🕯️ prefix, updates valueRef, and calls onChangeRef for immediate save.
  onError handler follows the same pattern with fallback verse.

/STORY COMMAND (logTriggers.ts + Logs.tsx + queries.ts + api.ts)

  self-care data (10). Together AI generates 1-2 paragraph personal story
  (512 token max). Creates generated_story log entry.
  USERSHIP GATE: req.user.tags check — returns 403 for non-Usership.
  onSuccess appends story to log text with 📖 prefix (same persistence
  pattern as /prayer fix). displayableEvents updated.

  /prayer /story /scan /qi /assembly /phys /qos /fast /breathe
  /freeze /silent /synth /radio /night /system
  Plus Ctrl+Enter shortcut documentation.
  Rendered in SYSTEM: Block with font-mono whitespace-pre.

MEMORY BUTTON LAG FIX (MemoryWidget.tsx)
  Root cause: recordSignal() called synchronously between setClickedButtonIndex
  (visual feedback) and createMemory (API call). recordSignal does:
  - localStorage.setItem with JSON.stringify of up to 1000 signals
  - conditional analyzeIntentions() with 60+ pattern matchers
  Both block the React render commit.
  Fix: moved recordSignal() into setTimeout(0) after createMemory call.
  React commits visual feedback immediately, signal work deferred.
  Consistent with Async Signal Recording doctrine (rev K).

ABOUT.TSX BUILD FIX
  Badge Codex v15 title contained embedded double quotes inside JSX
  value="..." attribute, terminating the string early. Replaced with
  single quotes. Remote already had the fix in v67 — retained on rebase.
