## QIE v70 ADDITIONS

### Pattern 84: integration-depth-lock
- **Trigger:** P43 (intention-completion-arc) + P81 (cognitive-depth-arc) + P76 (morning-coherence-launch) all active simultaneously
- **Confidence:** `Math.min(0.82 + (avgConf - 0.73) * 0.60, 0.94)` — boost scales from average confidence of the three contributing arcs
- **Widget:** systemProgress
- **Timing:** passive
- **Reason template:** `INTEGRATION DEPTH LOCK: All three inner arcs confirmed — morning launch · cognitive depth · intention completion. Full-stack operator mode. Completion X% · Cognition X% · Launch X%.`
- **Key design:** First QIE pattern to detect co-presence of three NAMED PATTERNS rather than raw signals. The system compounds its own certainty.

### Pattern 85: recovery-momentum-lock
- **Trigger:** selfcare ≥3 in 7d AND (≥2 negative→positive mood recovery pairs within 6h each OR ≥3 resilience signals in 7d)
- **Recovery pair detection:** For each depleting mood signal, checks if a restoring mood signal follows within 6h. Depleting: anxious/overwhelmed/tired/exhausted/depleted. Restoring: calm/peaceful/content/energized/restored/clear/grounded.
- **Confidence:** `Math.min(0.70 + (selfCare-3)*0.05 + pairBonus + resilienceBonus, 0.88)`
- **Widget:** selfcare
- **Timing:** passive
- **Reason template:** `RECOVERY MOMENTUM LOCK: N selfcare signals in 7d · N recovery arcs · N resilience signals. Recovery is now a pattern — not crisis response, but active maintenance protocol sustained across the week.`
- **Distinction from P48:** P48 fires on a single arc (depleted → care → restored). P85 fires when the arc repeats across a week — recovery as maintained practice.
