## DEVICE SUMMARY

Two-part 316L stainless steel body, 40mm x 40mm x 5mm target silhouette.
Top face: camera + 1" square OLED + a single "Copy" button. Bottom face:
mirror-polished stainless steel with a ceramic charging window for Qi
wireless power. ESP32-S3 compute, Bosch BME680 environmental sensor,
notifications rendered as single-line pager-style text sourced from the
LOT AI (QOS/Memory Engine events), following the already-shipped "one
line, no alarm, exact moment" rule. The Copy button writes directly to the
existing `/logs` endpoint that already powers every user's Log tab — no
new server-side work needed for that path.

## KEY DESIGN DECISIONS

1. **Reused, did not invent, the Log tab integration.** Grepped
   `src/server/routes/api.ts`, confirmed `POST /logs` already exists and
   does exactly what the Copy button needs. The hardware spec treats this
   as zero-new-work on the server side.
2. **Named engineering trade-off on the 5mm target.** A thickness
   stack-up in Doc 3 shows Alpha-spec components land at ~10-12mm, not
   5mm — documented as a Phase 3-4 miniaturization target (thin-film
   battery, ultra-miniature camera module) rather than pretending 5mm is
   achievable on the first build.
3. **Flagged that metal blocks wireless charging.** Solid stainless steel
   defeats a Qi coil's magnetic flux. Resolved with a ceramic/sapphire
   window insert — the same approach stainless Apple Watch models use —
   rather than silently spec'ing a charging method that would not work.
4. **Called out camera privacy as a hard requirement, not an add-on.** A
   hardware-wired LED tied to the camera's power rail (not
   software-controlled), plus the existing COSMO® rule that a unit is
   inert without a verified, consenting paired profile.
5. **Split production into a 10-unit pilot + 90-unit batch**, not one
   100-unit commitment, so defects are caught cheaply before scaling.
6. **Reused the existing PDF pipeline** (`reportlab`, same pattern as
   `scripts/generate_badge_pdf_v19.py`) instead of introducing a new
   toolchain — and generated a real, verified PDF as a first artifact
   rather than leaving "PDF manuals" as prose-only.
