GAP CLOSED THIS SESSION
--------------------------------------------------------------------------------
1. Period compression — /story [day|week|month|year]:
   - logTriggers.ts: new parseStoryPeriod() pure helper (bare /story = 'day',
     unchanged default behavior — zero regression risk for existing usage).
   - Logs.tsx: story-mode handler now extracts the period, strips it from
     the saved log text, and sends it + badgeProgress to the mutation.
   - api.ts /api/story: HORIZON table maps each period to a createdAt floor
     (day: none/unchanged, week: 7d, month: 30d, year: 365d), a proportional
     take-count for entries/moods/self-care notes, and a target word count
     (100-200 / 150-250 / 200-300 / 250-350) so a year compresses to an arc,
     not a re-run of the same ten lines. 'day' preserves the exact prior
     query (no time filter, limit 200) — no behavior change for the
     already-shipped default path.
2. Arcade tie-in — chrono_scribe badge:
   - badges.ts: new BadgeType + Badge entry (rare, achievement_rpg category),
     alongside the existing arcade_run/arcade_entry/arcade_class cluster.
   - easter-eggs.ts: checkChronoScribe(period) — tracks distinct periods
     used in localStorage, awards once all four (day/week/month/year) have
     been invoked at least once. Mirrors the existing checkArcadeRun()
     pattern exactly (pure function, awardBadge() handles the unlock queue).
   - Logs.tsx: story mutation's onSuccess calls checkChronoScribe(period),
     wired via react-query's variables argument so the exact period
     requested (not a stale ref) drives the check.
   - api.ts: client-computed badgeProgress {earned, total} is folded into
     the story prompt as one ARCADE PROGRESS line, with an explicit prompt
     rule to weave it in as a single clause, never a scoreboard callout —
     keeps the narrative tone intact while still surfacing gamified
     evolution, matching S-2's directive.
3. /system help text updated: '/story [period]  Compressed story — day
   (default), week, month, year'.
