### 2a — Code Quality Issue: Block.tsx String Concatenation [FIXED]

```
FILE:     src/client/components/ui/Block.tsx
LINE:     ~131
SEVERITY: MINOR (style / maintainability)
STATUS:   FIXED THIS SESSION
```

**Before:**
```tsx
: '-ml-4 pl-4 pr-4 cursor-pointer transition-[background-color] ' + hoverClassName
```

**After (fixed):**
```tsx
: cn('-ml-4 pl-4 pr-4 cursor-pointer transition-[background-color]', hoverClassName)
```

Rationale: The entire file uses `cn()` (tailwind-merge wrapper) for class composition.
String concatenation bypassed the utility, risking class conflicts if `hoverClassName`
ever contained Tailwind classes that clash with the hardcoded set. Now consistent.
