R1 TIME TRACKING     CalendarEntry gained a `time` (HH:mm) field alongside
                     date. Add-entry form got a native <input type="time">
                     next to the text field. Entries now sort by date+time
                     (entrySortKey helper, '99:99' fallback keeps undated-
                     time entries at end of their day). Upcoming list and
                     the per-date entry list both render the time when set.
                     [SCHEDULE] log text includes the time when present.

R2 RELIABILITY       Upcoming-entries filter is now time-aware: today's
                     entries whose time has already passed drop out of the
                     "upcoming" list instead of lingering all day — the list
                     means what it says. Add-entry state (text/time) resets
                     on date switch so stale drafts can't leak onto the
                     wrong day. Submit button disables mid-mutation
                     (isSubmitting flag via onSettled) to prevent double-
                     fire from a fast double-click or double-Enter.

R3 CALENDAR ALERT    New component CalendarAlertToast.tsx. Polls logs every
   TOAST             30s (paused when tab hidden or off the /system route,
                     matching the existing EvolutionMilestoneToast pattern)
                     for timed calendar_entry logs. Fires a top-right toast
                     at two tiers:
                       [T-MINUS <n>M]     — entry due within 15 minutes
                       [SITREP] EVENT DUE — entry due now (blink class,
                                            reused from index.css, within
                                            5 min of/after due time)
                     Alerts dedupe per-entry-per-tier via localStorage
                     (calendar_alerts_seen, capped at last 200 keys) so a
                     reload doesn't repeat a notice already delivered.
                     Mounted in System.tsx next to EvolutionMilestoneToast.
                     Styling stays inside the existing minimal system: acc/
                     opacity tokens, tracking-widest uppercase labels,
                     tabular-nums for date/time — no new color, no new
                     visual language introduced.

R4 LOG TERMINAL      Logs.tsx CAL: block now shows time alongside date for
                     calendar_entry events (tabular-nums, `date · time`).
