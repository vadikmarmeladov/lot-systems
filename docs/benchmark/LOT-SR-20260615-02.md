## DESIGN DECISIONS

| Decision | Rationale |
|---|---|
| `briefSentRef` + localStorage double guard | Ref prevents same-session double-fire; localStorage prevents refires across page loads on the same day |
| Type codes instead of raw strings | MEMO/OBJ/COMM scan faster than note/task/call in a list; matches military log aesthetic |
| T+Nd over raw dates in upcoming list | Temporal distance is more immediately useful than calendar date when scanning |
| Overdue at opacity-20 with strikethrough | Past items shouldn't compete visually; they're informational only |
| STAND-TO above upcoming | TODAY events have highest urgency; should appear first |
| Clock at text-acc/30 | Visible but subordinate; doesn't compete with entry text |
