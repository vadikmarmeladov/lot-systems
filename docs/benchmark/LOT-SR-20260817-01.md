BUILD DETAIL — what shipped
--------------------------------------------------------------------------------
Basics.tsx renders the OPEN TAB: masthead, a static STATUS-LINE component
(NOT ON STRENGTH — honest default; no roster/billing state machine exists
yet, that's Month 2), a plain USD 100/mo rate line, the doctrine statement
("Issue, not sold. On strength or not, no tier between. Load fixed, cadence
fixed, rate fixed. The tab is the ledger."), and the 23-item ration manifest
as a nomenclature+cadence table (6 MONTHLY / 9 QUARTERLY / 5 SEMIANNUAL /
3 ANNUAL — invented, internally consistent, no real supplier claims; COGS
withheld per spec). Visual register is a deliberate, scoped deviation from
house style (docs/technical/LOT-STYLE-GUIDE.md: Arial + opacity hierarchy):
monospace stack (Liberation Mono with system-monospace fallbacks — no font
file ships with the repo, so the browser substitutes), white ground / black
ink, inversion-only hierarchy (emphasis = swap fg/bg, never color or size),
2px rules, zero border-radius, fixed-width grid columns. All of it lives in
one scoped <style> block inside Basics.tsx — tailwind.config.js and
index.css are untouched. Flagged in the component's own header comment so a
future style pass doesn't "fix" it back to Arial by mistake.

SCOPE HONESTLY NOT MET: the spec's Month-1 exit line — "a stranger can read
what LOT issues" — is only partly true. The nav slot lives inside app.tsx's
authenticated shell: `/api/me` requires a session, and App redirects
unauthenticated visitors to /login before Layout ever renders. Wiring
"Basics" live makes it reachable by any logged-in account (no Usership gate),
but not by a visitor with no account at all — true public reach would need
either a separate public route (the pattern StatusPage already uses) or a
change to the app-level auth gate, and neither was in the concrete
integration point this session found (the existing disabled nav item).
Recorded here rather than glossed over; a follow-up session can decide
whether that's worth a dedicated public page.
