## SYSTEM ARCHITECTURE

### LOT® Mail Stack

```
LOG (compose)
  └── /email to [name] [body]
        └── email-compose trigger (logTriggers.ts)
              └── useSendLotMail() → POST /api/lot-mail
                    ├── Persists to lot_mails table
                    ├── Resolves recipient by firstName (users table)
                    ├── Logs to Log archive (event: note, mailType: lot_mail_sent)
                    └── SSE emit → sync.emit('lotMail', payload)
                          └── SYNC (inbox)
                                └── LotMailInbox.tsx (real-time via sync.listen)
```

### Data Model: `lot_mails`

| Field | Type | Notes |
|---|---|---|
| id | UUID | Primary key |
| senderId | UUID → users | FK with CASCADE |
| receiverId | UUID → users | Nullable — set after name lookup |
| recipientName | STRING(128) | As typed in command |
| subject | STRING(256) | Optional |
| body | TEXT | Message content |
| isRead | BOOLEAN | Default false |
| createdAt | DATE | Auto |
| updatedAt | DATE | Auto |

**Indexes:** `(receiverId, isRead, createdAt)`, `(senderId, createdAt)`

## USER EXPERIENCE

### Compose in Log

```
/email to Hitomi Hey, want to connect for the cohort session?
```

→ Triggers `email-compose` signal
→ Parses recipient (`Hitomi`), body (`Hey, want to connect...`)
→ Resolves `Hitomi` → `users` table by `firstName ILIKE 'hitomi'`
→ Saves to `lot_mails`, emits SSE to recipient
→ Creates Log entry with event `note`, metadata `mailType: lot_mail_sent`
→ Shows `MAIL: MAIL SENT — delivered to recipient.` in Log

### Log Archive Display

Sent mail appears in past logs as:

```
MAIL:   → Hitomi
        Hey, want to connect for the cohort session?
```

### Inbox in Sync

Mail inbox appears below chat messages with:
- **Mail** tab (with unread count badge) / **Sent** tab
- Rows: `[time]  [sender]  [subject preview]  [unread dot]`
- Click to expand full body, auto-marks as read
- Real-time: new mail arrives via SSE without page refresh

## LOT COMMUNITY INTEGRATION

**Recipient Resolution:** `firstName ILIKE` search against `users` table — the same user graph used by Cohort Dating. Any LOT Community member can be addressed by first name.

**Sync Integration:** Mail inbox is embedded in the existing Sync component alongside LOT Chat. Unread count updates live via the same SSE pipeline that drives chat messages.

**Log Integration:** Every sent mail creates a `note` Log entry tagged `mailType: lot_mail_sent`. This integrates with the Signal Archive and QIE pattern recognition — mail frequency and recipients become part of the behavioral signal stream.

## DESIGN PRINCIPLES HONORED

| Principle | Implementation |
|---|---|
| **Simplest possible** | No threads, no attachments, no CC — pure body + optional subject |
| **LOT® style** | Follows Block/GhostButton/Tag UI primitives, text-first, opacity hierarchy |
| **SSE-native** | Real-time delivery via existing sync EventEmitter, no new WebSocket infra |
| **Log-first compose** | Command lives in the Log field — zero new UI surfaces to learn |
