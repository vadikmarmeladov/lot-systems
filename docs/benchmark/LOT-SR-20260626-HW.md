08 // LEARNINGS + DOCTRINE
--------------------------------------------------------------------------------

  L01  E-paper is the correct display for a pager-class device.
       The 0 µA image retention transforms battery math:
       150 mAh → 48h display lifetime vs. 4h with OLED at same capacity.

  L02  316L stainless steel enables Qi charging without non-metallic
       inserts. The non-magnetic property of 316L is the enabling condition.
       Aluminum (also non-magnetic) would also work but lacks the
       premium mirror-polish quality of SS for the COSMO brand.

  L03  PCBWay turnkey is the correct choice at 100 units.
       The crossover to in-house PCBA is ~500+ units with dedicated SMT line.
       Below 500: PCBWay PCBA cost < (equipment + operator + time).

  L04  Session compression (CBOR, 48 bytes) is essential for a device
       that may be offline for 48h+ (deep sleep). The 32-session ring
       buffer ensures no data loss across a 6-day offline period.

  L05  The LOT API connector architecture (device_api.ts as separate route)
       cleanly separates device concerns from user/chat concerns.
       The COPY event writes to the existing logs table — zero frontend
       structural change required to appear in Log tab.
