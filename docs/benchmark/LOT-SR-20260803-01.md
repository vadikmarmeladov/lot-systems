### Fixes Applied This Session

**1. `src/client/components/ui/WidgetErrorBoundary.tsx`**

Added `type="button"` to the Retry button inside the error fallback render. Without this, browsers default to `type="submit"` for `<button>` elements inside a `<form>`, which could silently submit any ancestor form when a user clicks Retry.

```tsx
// Before
<button onClick={...} className="underline cursor-pointer" style={...}>

// After
<button type="button" onClick={...} className="underline cursor-pointer" style={...}>
```

**2. `src/client/components/StatusPage.tsx`**

Added conditional guard on `buildDate` before calling `formatDate()`. If the API response omits `buildDate` (e.g., cached or partial response), the previous code would pass `undefined` into `new Date()`, producing `"Invalid Date"` in the UI.

```tsx
// Before
<div>Build: {formatDate(status.buildDate)}</div>

// After
<div>Build: {status.buildDate ? formatDate(status.buildDate) : 'N/A'}</div>
```
