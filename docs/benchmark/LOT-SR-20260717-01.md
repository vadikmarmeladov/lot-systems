## 4. ERRORS & WARNINGS

### 4a. Fixed This Session

**[FIXED] RecipeWidget — unsafe `weather as any` type cast**
- File: `src/client/components/RecipeWidget.tsx`
- The `weather` store is typed `atom<WeatherRecord | null>` where `WeatherRecord` has `tempKelvin: number | null` and `description: string | null` as proper fields. The `(weather as any)?.tempKelvin` and `(weather as any)?.description` casts were silently bypassing this type safety.
- Fix: replaced with `weather?.tempKelvin ?? undefined` and `weather?.description ?? undefined`.

**[FIXED] RecipeWidget — setTimeout memory leaks on unmount**
- File: `src/client/components/RecipeWidget.tsx`
- Three `setTimeout` calls (fade-in, farewell fade, dismiss) ran without cleanup. If the component unmounted during any animation — e.g. navigation away during a 3-second farewell fade — setState would be called on an unmounted component.
- Fix: `farewellTimers` ref tracks all active timers; `useEffect` cleanup clears them on unmount; fade-in timeout returns `clearTimeout` directly.

**[FIXED] MonthlyPulseWidget — setTimeout memory leaks on unmount**
- File: `src/client/components/MonthlyPulseWidget.tsx`
- Same pattern: `setTimeout(() => setIsShown(true), 100)` and two dismiss timeouts ran without cleanup.
- Fix: `dismissTimers` ref + `useEffect` cleanup; fade-in timeout returns `clearTimeout`; `handleDismiss` clears any prior timers before setting new ones.

**[FIXED] Block.tsx — interactive `<span>` elements not keyboard-accessible**
- File: `src/client/components/ui/Block.tsx`
- The label span (`onLabelClick`) and content span (`onClick` / `onChildrenClick`) were clickable but had no `role`, `tabIndex`, or `onKeyDown`. Keyboard-only users (and screen readers) could not activate them.
- Fix: added `role="button"`, `tabIndex={0}`, and `onKeyDown` (Enter/Space) to both interactive span variants. Non-interactive spans are unchanged.
