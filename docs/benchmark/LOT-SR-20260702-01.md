FIX LOG:
1. `npm run server:build` returned exit 2 on HEAD *before* any of this
   session's feature edits — confirmed by stashing the feature change and
   re-running. Root cause: tsconfig.server.json's `moduleResolution: "node"`
   and `baseUrl` are hard errors (TS5107/TS5101) under the TypeScript 5.9.3
   in this environment, and `noEmitOnError: false` let the build "succeed"
   with emitted JS while `npm run server:build`'s actual exit code was 2 —
   a silently red build. This predates this session; not caused by it.
2. Discovered `node_modules` was not installed in this environment at all
   (`npm ci` failed outright — 1 entry in node_modules, no .bin). Ran
   `npm ci --legacy-peer-deps` (plain `npm ci` hit a genuine, pre-existing
   peer conflict: root `nanostores@^0.9.0` vs `@nanostores/react@0.4.1`
   which wants `nanostores@^0.7.0`).
3. Added `"ignoreDeprecations": "5.0"` to tsconfig.server.json (first
   attempt used "6.0", which is invalid for TS 5.9.3 — TS 6.0 does not
   exist yet; corrected in the same session before commit).
