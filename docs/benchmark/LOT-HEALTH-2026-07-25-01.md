04 // FIXES APPLIED THIS SESSION
--------------------------------------------------------------------------------

FIX A  ACCESSIBILITY  focus-visible keyboard ring            src/client/index.css
       ─────────────────────────────────────────────────────────────────────────
       PROBLEM:  `*:focus { outline-none }` removed ALL focus indicators
                 from ALL elements site-wide. Keyboard users (tab navigation)
                 had no visual cue for focused elements. Fails WCAG 2.1 AA
                 SC 2.4.7 (Focus Visible).

       FIX:      Added `*:focus-visible` rule with a 2px accent-colored
                 outline at 55% opacity + 2px offset. Uses the `:focus-visible`
                 selector so the ring is INVISIBLE for mouse/touch focus events
                 (no visual noise) and VISIBLE for keyboard navigation only.
                 This is the pattern used by Linear, Vercel, Stripe, and all
                 modern WCAG-compliant design systems.

       DIFF:
         + *:focus-visible {
         +   outline: 2px solid rgb(var(--acc-color-default) / 0.55);
         +   outline-offset: 2px;
         +   border-radius: 2px;
         + }

FIX B  ACCESSIBILITY  prefers-reduced-motion guard           src/client/index.css
       ─────────────────────────────────────────────────────────────────────────
       PROBLEM:  Site has 6+ distinct CSS animations (convergence-breathe,
                 soft-blink, evolved-transition, evolved-glow, theme-water-flow,
                 etc.). Zero `prefers-reduced-motion` protection meant all
                 animations ran unconditionally, including for users with
                 vestibular disorders. Fails WCAG 2.1 SC 2.3.3 (Animation
                 from Interactions, AAA) and is a baseline expectation on
                 any top-tier designer site.

       FIX:      Added standard `@media (prefers-reduced-motion: reduce)` block
                 at end of index.css. When OS motion-reduction is on, all
                 animation durations collapse to 0.01ms (effectively instant)
                 and transition durations do the same. Pattern matches
                 Bootstrap 5, Material UI, Radix UI, and Tailwind's own reset.

       DIFF:
         + @media (prefers-reduced-motion: reduce) {
         +   *, *::before, *::after {
         +     animation-duration: 0.01ms !important;
         +     animation-iteration-count: 1 !important;
         +     transition-duration: 0.01ms !important;
         +     scroll-behavior: auto !important;
         +   }
         + }

FIX C  DESIGN QUALITY  ToggleSection animation               src/client/components/ui/ToggleSection.tsx
       ─────────────────────────────────────────────────────────────────────────
       PROBLEM 1 (animation):
                 `max-h-[2000px] → max-h-0` is a known CSS antipattern.
                 The transition eases across the FULL 2000px range regardless
                 of actual content height, so a 100px section "snaps" open
                 (300ms of invisible travel through ~1900px) instead of
                 expanding smoothly. The closing direction is equally broken.

       FIX:      CSS grid row expansion — `grid-rows-[0fr] → grid-rows-[1fr]`
                 with `transition-[grid-template-rows]`. The browser animates
                 the ACTUAL content height, producing a pixel-perfect smooth
                 expand/collapse at any content size. Inner wrapper needs
                 `min-h-0` to allow row to shrink to zero.

       PROBLEM 2 (dead code):
                 Button className contained `indent > 0 && 'pl-' + (indent * 16)`.
                 Tailwind JIT requires static class names at build time — a
                 runtime-concatenated string like `'pl-' + 32` is never in the
                 emitted CSS. The style was already applied via an inline style
                 attribute on the same element, making this code completely dead.

       FIX:      Removed the broken dynamic class. Inline style already handles
                 indent correctly.

       BEFORE:
         <div className={cn(
           'overflow-hidden transition-all duration-300',
           isOpen ? 'max-h-[2000px] opacity-100' : 'max-h-0 opacity-0'
         )}>

       AFTER:
         <div className={cn(
           'grid transition-[grid-template-rows] duration-300 ease-in-out',
           isOpen ? 'grid-rows-[1fr]' : 'grid-rows-[0fr]'
         )}>
           <div className="min-h-0 overflow-hidden">
