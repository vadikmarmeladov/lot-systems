DETAIL
--------------------------------------------------------------------------------
CalendarWidget.tsx foundation (month grid + note/task/call entries logged as
`calendar_entry`) had no time-tracking. Added:
  - Per-entry TRACK toggle in the selected-date entry list; live HH:MM:SS
    readout ticks via requestAnimationFrame (mirrors TimeWidget's stopwatch
    pattern — startTimeRef + rAF tick loop).
  - Only one active session at a time; starting a new one auto-stops and logs
    the prior one first.
  - Session state persisted to localStorage (calendar_active_tracking) with
    wall-clock startedAtIso, not perf.now (which resets on reload) — a page
    refresh mid-track resumes the correct elapsed time instead of losing it.
  - On stop: writes `calendar_time_log` to the Log (date, text, entryType,
    durationMs, startedAt, endedAt) via the existing useCreateLog() mutation —
    same pattern CalendarWidget already used for calendar_entry.
  - Persistent status row (visible whether the calendar grid is open or
    collapsed) shows the active session and a one-click stop.

CalendarEventNotification.tsx (new): a stacked, terminal-grid toast — DTG
timestamp (dayjs().utc().format('DDHHmm[Z] MMMYY')), bracketed code
([CAL·TRK], [CAL·LOG], [CAL·SCHED]), all-caps title, font-mono, grid-fill-light
background matching the existing EvolutionMilestoneToast/Logs.tsx aesthetic.
Distinct from EvolutionMilestoneToast (single-slot, bottom-center, localStorage-
polled): this one supports up to 3 stacked notices, bottom-right, fired directly
from widget events rather than polled. Auto-dismiss 4.5s, click-to-dismiss.
Notices fire on: entry scheduled, tracking engaged, time logged.

Server: added `calendar_time_log` to the `/api/logs` displayableEvents
allowlist (api.ts) — without this the log would write but never render,
same trap the existing `calendar_entry` case already avoided.

Logs.tsx: added a `calendar_time_log` render branch immediately after the
existing `calendar_entry` branch, matching its Block/label/opacity idiom
exactly (label CAL-TRK:, entry text, entryType + tabular-nums duration).
