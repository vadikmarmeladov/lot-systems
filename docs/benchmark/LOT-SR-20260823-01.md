FINDINGS — LOG CONTEXT SYNC (WEATHER, TIME, USERS ONLINE) & MILITARY FORMAT
--------------------------------------------------------------------------------
Interactive-widget context is NOT synced per-widget — it is threaded once,
uniformly, onto every log entry's `context` JSONB field (timeZone, city,
country, temperature, humidity, weatherDescription), then rendered as a
single contextLine prefix in memory.ts (buildPrompt, ~line 255-267) ahead of
every formatted log. usersOnline/usersTotal are separately seeded from
GET /api/me into nanostores on load (2026-06-30 fix, still intact — no "0
flash" regression found) and displayed directly in System.tsx, not routed
through the Log. This is the correct architecture already, not a gap:
weather/time context reaches the AI on every entry; presence counts are a
live dashboard stat, not a loggable event.

The "military communications" format IS real and live in Logs.tsx: COMM:,
CARE:, PLAN:, INTENT:, SYS:, QOS:, COHR-COMM:, BIOFIELD, and 6+ more
labeled blocks render every signal-derived event. No gap found here.
