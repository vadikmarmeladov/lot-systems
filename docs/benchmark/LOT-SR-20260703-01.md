── WARNING RESOLVED (FIXED THIS SESSION) ───────────────────────────────────────

  [WARNING] tsconfig.server.json raises TS5107 + TS5101 on every build.

  File:    tsconfig.server.json
  Cause:   TypeScript 6.0.2 promoted `moduleResolution: "node"` and `baseUrl`
           from "TS 7.0 future" warnings to actual diagnostic errors (TS5107,
           TS5101). Prior benchmark noted these as "non-blocking TS 7.0 future"
           but TS has since shipped 6.0.2 which activates them.
  Impact:  Clutters build output; two TS error lines on every `tsc` invocation.
           Build exit code remains 0 due to `noEmitOnError: false` (no
           functional regression), but output quality degrades and makes
           identifying real new errors harder.
  Fix:     Added `"ignoreDeprecations": "6.0"` to tsconfig.server.json
           compilerOptions per official TypeScript guidance (aka.ms/ts6).
           TS5107 and TS5101 no longer appear in build output.
  Note:    Full migration to `moduleResolution: "bundler"` is the long-term
           path but requires path alias changes — deferred to a dedicated
           session.
