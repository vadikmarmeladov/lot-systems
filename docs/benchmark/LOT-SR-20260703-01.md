02 // DESIGN — SIMPLEST LOT EMAIL
--------------------------------------------------------------------------------
LOG COMMAND:     /email to [Name] [optional body]  (also /mail, also ✉️/✉/📧
                 — but the emoji alone doesn't fire without "to <name>")
                 Opens an inline compose panel under the log line: recipient
                 name pre-filled, a body textarea, Send / Cancel. Matches the
                 exact S-2 example verbatim: "/email to Hitomi." opens the
                 panel addressed to Hitomi with an empty body to fill in.

RECIPIENT RESOLUTION:
                 POST /api/mail resolves "Hitomi" (first token = firstName,
                 remaining tokens = lastName) via case-insensitive ILIKE
                 against the User table — i.e. LOT Community at large, the
                 same population Cohort Dating draws its matches from.
                 404 with a hint ("No user named X in LOT Community") if
                 nobody matches; 400 if you address yourself.

DELIVERY:        New `lot_mails` table (fromUserId/toUserId/subject/body/
                 read), independent of the existing chat_messages and
                 direct_messages tables — mail is its own concept, not a
                 relabeled DM. Sender gets an inline "✉ Sent to X." status
                 in Log. Recipient gets it in real time via a new `lot_mail`
                 SSE event — routed server-side ONLY to the matching
                 toUserId (fixed the same pattern the existing
                 `direct_message` SSE emit lacks: that event has never
                 actually been forwarded by the /sync gateway switch,
                 since no case for it exists — direct messages currently
                 only ever appear after a manual refetch, not live. Did
                 not touch that pre-existing gap; out of scope for this
                 session, noted here for a future pass).

SYNC INTEGRATION: "New messages appear in Sync" — Sync now has a Chat | Mail
                 tab strip. Mail shows an unread-count badge on the tab
                 label, live-refreshes via the SSE event, and lists inbox
                 messages (sender, subject/preview, click to expand + mark
                 read). This is the literal answer to the S-2 requirement:
                 mail lives inside LOT Chat (Sync), not a separate page.

COHORT DATING / COMMUNITY INTEGRATION:
                 - Cohort Connect widget's "Send message" button previously
                   went nowhere useful (`stores.goTo('sync')` — a dead
                   pointer, not wired to the specific match at all). Fixed:
                   it now hands off to Log with `/email to <FirstName> `
                   pre-filled and focused, so a cohort match becomes a mail
                   in one click.
                 - Chat Catalyst widget (the "cohort member is online, want
                   to connect?" prompt) gains a second "✉ Mail" action next
                   to its existing "Connect" button, same hand-off pattern.
