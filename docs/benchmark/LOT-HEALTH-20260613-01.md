DETAIL — HIGH SEVERITY

W-01 · src/client/index.css · lines 82-84
  Code:     *:focus { @apply outline-none; }
  Impact:   WCAG 2.1 AA violation — keyboard and AT users lose all focus indication.
            Affects every interactive element across the entire application.
  Fix:      Replace with per-element intent:
              *:focus { @apply outline-none; }                 /* keep */
              *:focus-visible { @apply outline-2 outline-acc outline-offset-2; }
            This suppresses focus rings on mouse click only; restores them for keyboard.

W-02 · src/server/server.ts
  Code:     'script-src': ["'self'", "'unsafe-inline'", ...]
            'img-src': ['*', 'data:']
  Impact:   If this file is ever accidentally loaded (import path error, refactor),
            it degrades CSP from strict to permissive; wide-open img-src allows
            data exfiltration via pixel tracking.
  Context:  Production entry is src/server/index.ts (strict CSP); server.ts is
            a dev-era duplicate. Deferred note in SR-08 confirms it is known debt.
  Fix:      Delete server.ts. Production path confirmed as dist/server/server/index.js.

W-03 · @anthropic-ai/sdk: ^0.32.1
  Impact:   Claude 3.5 Sonnet, Claude 3.7, and claude-sonnet-4-6 all released after
            0.32.1. Missing: streaming improvements, extended thinking, token budgets,
            batch API, updated tool-use schema, model aliases.
  Risk:     ai-engines.ts calls Anthropic models with outdated client — may silently
            use deprecated parameters or miss new capabilities.
  Fix:      yarn add @anthropic-ai/sdk@latest + audit ai-engines.ts for API changes.

W-04 · axios: ^0.27.2
  Impact:   v0.x has open CVEs (SSRF and prototype pollution in older builds).
            v1.0 was a breaking release; project should migrate.
  Fix:      yarn add axios@^1.7.0 + test all HTTP call sites.

DETAIL — MEDIUM SEVERITY

W-05 · src/client/About.tsx (333,449 bytes)
  Impact:   Largest component in codebase by 10×. Every page load parses the entire
            file. No React.lazy() boundary. Cold-start parse cost hits even users
            who never visit the About route.
  Fix:      Split into 30+ section components; lazy-import behind React.lazy().
            Priority: extract static text sections first (zero logic to move).

W-06 · AwarenessDashboard.tsx:53
  Code:     try { recordSignal(...) } catch (e) {}
  Impact:   QIE signal recording failures are invisible. If the signal pipeline
            breaks, user data is silently lost with no observability.
  Fix:      catch (e) { console.error('[QIE] signal record failed', e) }
            Downstream: wire to centralized error boundary or Sentry when available.

W-07 · EnergyCapacitor.tsx:31
  Code:     const cycleView = () => { ... } (inside render body, no useCallback)
  Impact:   New function reference on every parent render. Any child passing this
            as prop triggers unnecessary re-render (violates RENDER-ISOLATION doctrine).
  Fix:      const cycleView = useCallback(() => { ... }, [])

W-08 · AwarenessDashboard.tsx:103
  Code:     color="#acc"
  Impact:   #acc is not a valid 6-digit hex color. Tag component receives a broken
            value; renders as black or throws depending on implementation.
  Correct:  Tailwind acc token → use className="text-acc" or pass the CSS var:
            color="rgb(var(--acc-color-default))"

W-09 · app.yaml:6
  Code:     branch: claude/february-2025-updates-HZZTF
  Impact:   DigitalOcean deploys from a branch that is ~16 months stale. If the
            platform triggers an autodeploy from the configured branch, it would
            roll back to a 2025-02 codebase. Production likely running current
            only because the last manual deploy was forced.
  Fix:      Update app.yaml branch field to master (or the current ship target).
