FEATURE SUMMARY
--------------------------------------------------------------------------------
LOG:      `/email to [Name] [body]` (also ✉️ / ✉ / 📧, or bare keyword
          `/mail`) opens an inline compose panel in the current Log entry.
          Wired into the existing logTriggers.ts detector alongside /synth,
          /qos, /assembly, /system etc. — same pattern, one more rule.
SYNC:     Sync gained a Chat | Mail tab strip. Mail tab shows unread count
          (SSE-pushed via a new `lot_mail` sync event, delivered only to the
          intended recipient — server routes it same as chat_message).
          EmailInbox.tsx renders the inbox list, click-to-expand a message,
          auto-marks read.
COMMUNITY/COHORT: ChatCatalystWidget (the existing Cohort Dating /
          "Connect" surface) gained a secondary "✉ Mail" button next to its
          existing Connect action whenever the catalyst names a specific
          cohort member — it pre-fills `/email to <Name>` directly into the
          Log input and jumps there. No parallel messaging stack: LOT Mail
          reuses the User model, the Sync SSE channel, and the Log trigger
          grid that Chat and Cohort already run on.
DB:       New `lot_mails` table (Sequelize model + migration), indexed on
          (toUserId, read, createdAt) and (fromUserId, createdAt). Migration
          not run against a live database in this sandboxed session — no DB
          was available to this session; schema verified by structural
          comparison against sibling migrations only. Flagged for the next
          session with DB access to run `npm run migrations:up` and confirm.
