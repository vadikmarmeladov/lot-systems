### Architecture decision: standalone public page, not an SPA route

The main app shell (`app.tsx`) redirects any unauthenticated visitor to
`/login` — there is no public surface inside the SPA. LOT already has a
precedent for real public pages that bypass that gate: `/about`,
`/status`, `/u/:userId`, each a dedicated esbuild entry + its own Fastify
route registered before the auth-gated SPA routes. `/basics` follows the
same pattern exactly (mirrors `/status`: `generic-spa` template,
`scriptName: 'basics'`), so a stranger with no session can load it
directly — satisfying "a stranger can read what LOT issues" without
inventing new server auth-bypass logic.

The in-app nav "Basics" button previously had neither `route` nor
`onClick` — permanently disabled. `Layout.tsx`'s `NavItem`/`NavButton`
gained an `href` option (Button already supports anchor rendering); the
tab now does a real navigation to `/basics`, same convention already used
by the `/status` link in `Settings.tsx`. One page serves both the public
OPEN TAB and the logged-in tab click — "the ledger is the marketing, no
layer between public and manifest" holds structurally, not just as copy.

### Visual identity

Global CSS already defaults `--base-color: #fff` / `--acc-color: 0 0 0`
(true white ground / black ink) and Tailwind's default `font-mono` stack
includes Liberation Mono — both already used elsewhere in the app for a
"military-log aesthetic" (see `SystemProgressWidget.tsx`). Basics.tsx
builds on that rather than importing new fonts or tokens:
- `font-mono` throughout, `font-bold` for headers (LiberationMono-Bold register)
- every rule and card border is `border-2` (no 1px hairlines)
- zero `rounded*` classes anywhere in the component — square corners only
- hierarchy comes from `bg-acc text-bac` (full inversion) on section
  labels, category rows, and the price bar — no accent color, no icons
