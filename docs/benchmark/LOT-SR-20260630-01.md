03 // PERFORMANCE ANOMALIES
--------------------------------------------------------------------------------

3A · SIDE EFFECTS INSIDE useMemo — System.tsx:229–233
  Code:
    const quantumState = React.useMemo(() => {
      analyzeIntentions()   // <-- side effect
      recomputeAssembly()   // <-- side effect
      return getUserState()
    }, [logs])
  Issue: React's rules of hooks forbid side effects in memo bodies. React may
         call memos multiple times (concurrent mode, StrictMode double-invoke).
         analyzeIntentions + recomputeAssembly could run 2x on every render.
  Severity: LOW (not crashing; double computation is wasteful but not broken)
  Recommendation: Move side effects into a useEffect with the same [logs]
                  dependency; call getUserState() after they run.

3B · Math.random() IN JSX RENDER BODY — System.tsx:847, 896
  Code (Intentions widget, line 847):
    const cooldownPeriod = twoDaysMs + Math.random() * (threeDaysMs - twoDaysMs)
  Code (Subscribe widget, line 896):
    const shouldShow = Math.random() < 0.2
  Issue: Random values computed inline in IIFE JSX blocks recalculate on every
         parent re-render. Subscribe widget has 20% chance to flip on/off each
         render. Intentions cooldown changes on every render.
  Severity: LOW-MED (UI flickers unlikely in practice; causes non-deterministic
            test behaviour and SSR hydration mismatch if SSR is ever added)
  Recommendation: Compute these once in a useRef/useEffect/useState on mount,
                  not inline in the render pass.

3C · LARGE IIFE BLOCKS IN JSX — System.tsx:789–898
  Three consecutive IIFE sections (SelfCare, Intentions, Subscribe) each
  contain 30–50 lines of localStorage reads, date math, and conditionals
  inline inside JSX. This is a readability/debuggability issue rather than
  a runtime perf problem, but it violates "instrument-panel clarity" expected
  at a top-tier designer product level.
  Recommendation: Extract each to a named boolean: showSelfCare, showIntentions,
                  showSubscribe — computed above the return via useMemo.
