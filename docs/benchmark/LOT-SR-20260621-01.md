LOT MAIL — SYSTEM ARCHITECTURE

           subject TEXT? | body TEXT | readAt DATE? | createdAt | updatedAt

  Migration: migrations/20260621120000_add-lot-mail.cjs

TYPES
  src/shared/types/index.ts:
    LotMail { id | senderId | receiverId | subject | body | readAt | createdAt | updatedAt }
    PublicLotMail = LotMail & { sender: {...} | null; receiver: {...} | null }
    SyncEvents.lot_mail added — typed SSE delivery

SERVER ROUTES (all behind auth)
  GET  /api/lot-mail              inbox (receiverId = me, limit 50, sender hydrated)
  GET  /api/lot-mail/sent         sent (senderId = me, limit 50, receiver hydrated)
  POST /api/lot-mail              send { receiverId, subject?, body } → emits lot_mail SSE
  PUT  /api/lot-mail/:id/read     mark read (receiver only)
  GET  /api/lot-mail/search-users search users by firstName (for /email to <name> autocomplete)

SSE ROUTING
  case 'lot_mail' in SSE switch: data delivered only to mail.receiverId.
  Sender gets no echo — clean single-delivery model.

COHORT DATING / LOT COMMUNITY
  Recipient search (/api/lot-mail/search-users) queries all community users
  by firstName prefix. This surfaces the same user pool as LOT Community,
  making LOT Mail the native channel for Cohort Dating correspondence.
  The /email to <name> flow is the fastest path from Log to community contact.

USER FLOWS

  COMPOSE FROM LOG:
    1. User types "/email to Hitomi" in current log entry
    2. 'email-compose' trigger fires → LotMailCompose modal opens, "Hitomi" pre-filled
    3. Search results appear (useSearchUsersForMail, 2+ chars)
    4. User selects recipient, writes body, hits Send (or ⌘↵)
    5. POST /api/lot-mail → SSE lot_mail emitted to receiver only
    6. Modal closes

  RECEIVE (SYNC):
    1. lot_mail SSE arrives for logged-in recipient
    2. useLotMailInbox invalidated → Mail strip in Sync shows unread count
    3. User clicks "Mail · 1" → inbox panel expands → message row with unread dot
    4. Click message row → LotMailThread modal → body shown, readAt stamped

  COMPOSE FROM SYNC:
    1. User clicks "compose" link in Sync's Mail strip
    2. LotMailCompose modal opens (no prefill)
    3. Same flow as above
