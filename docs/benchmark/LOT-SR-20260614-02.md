## MISSION

Design, develop, and deploy the simplest LOT® Email system in LOT® style.

- Compose messages in Log with `/email to Hitomi.`
- New messages appear in Sync
- Incorporate with LOT Chat (Sync) and Cohort Dating through LOT Community

================================================================================
## ARCHITECTURE DECISION

LOT Mail is the simplest possible in-app email layer built on existing infrastructure:

- **Trigger**: `/email` keyword (or ✉ emoji) in Log fires `send-email` LogTrigger
- **Parse**: `/email to Name. Body text` → toName + body
- **Store**: `lot_mail` table (new) for inbox/sent history
- **Deliver**: Creates a `ChatMessage` in Sync with `✉ TO NAME · body` prefix → SSE broadcast
- **Render**: Sync detects `✉` prefix and renders with left-border accent

No new SSE event type needed. No changes to ChatMessage schema.
Mail rides the existing `chat_message` SSE channel.

## API SURFACE

### POST /api/lot-mail
```
Body: { toName: string, body: string }
→ Creates LotMail record
→ Creates ChatMessage ("✉ TO NAME · body")
→ Broadcasts via SSE chat_message to Sync
→ Logs lot_mail_sent event
Response: { id, toName, body, createdAt }
```

### GET /api/lot-mail
```
→ Returns { sent: LotMail[], inbox: LotMailInboxItem[] }
→ Inbox: mails addressed to user's firstName (Op.iLike)
→ Sent: mails from current user
```
