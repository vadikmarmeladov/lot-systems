## ARCHITECTURE NOTES

**Alert deduplication:** `alertedRef.current` is a `Set<string>` in a React ref — session-scoped, non-reactive. On page refresh alerts may re-fire if events are still within threshold windows. This is intentional: a page reload during an event window should surface the alert again.

**Performance:** 1-second re-renders are isolated to the CalendarWidget subtree. `entries` (expensive) recomputes only on `logs` change. `todayEntries` recomputes every second only when entries exist for today. Zero network calls per tick; alert logs are gated by the Set.

**Backward compatibility:** Existing `calendar_entry` logs without `time` field render correctly — time input is optional throughout, `computeMinutesUntil` returns `null`, T-minus shows `——`.
