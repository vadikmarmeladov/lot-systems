  lot_mails table        senderId / receiverId / body / isRead + two indexes
  GET  /api/lot-mail/inbox   returns last 30 mails with senderName joined
  POST /api/lot-mail         { recipientName, body } → find user by firstName
                             → create record → SSE emit lot_mail
  PUT  /api/lot-mail/:id/read  mark as read
  LogTrigger 'lot-mail'   fires on /email or ✉️/📧 in log text
  NoteEditor handler       regex /email\s+to\s+([A-Za-z]+)[.,]?\s+([\s\S]+)/i

                           (mailSentRef guards against duplicates)
