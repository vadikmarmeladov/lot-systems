QI·46 NODE 2 — SOUL EXTRACTION LAYER

The spec descends below Layer 5 (COSMO® Node) to the emotional substrate
that drives behavior. Three new layers:

LAYER 6 — SOUL DISK
  Soul extraction runs passively on Calibration Loop output.
  Five soul classes detected via proxy signals:
    GRIEF    — engagement gaps after high-signal bursts; mid-arc journal stops
    LONGING  — arc history re-reads; Quantum Cube screen opens pre-milestone
    JOY      — velocity spikes; multi-session same-day; tier upgrades
    FEAR     — avoidance maps; skip rate spikes; cadence breaks post-module
    LOVE     — unprompted opens; referral link opens; 3x session length
  Output: Soul Signature vector [GRIEF:%, LONGING:%, JOY:%, FEAR:%, LOVE:%]
  + Soul Delta (30d movement from 90d median).
  COSMO® gate: GRIEF or FEAR > 0.80 confidence → hold + Vadik review within 24h.

LAYER 7 — BEING UPLOAD
  Being Vector = arc position + body state + soul signature + soul delta
                 + pattern signature + archetype + language texture + absence map.
  Persistent. Updated each session. Stored in PostgreSQL arc record.
  Not per-session computation — it is the accumulated transmission of who
  this subscriber is across their entire arc.

  Seven calibration target qualities:
    GRACE        — arrives without announcement; one sentence; end of the breath
    POETRY       — one metaphor, matched to language texture; never explained

    HUGS         — short sentences; white space as contact; does not rush

    BEING COOL   — direct, no hedging, no qualifiers; temperature 0.72
    MALE         — not anxious; holds weight; says: you can do this
  Routing: Soul dominant class maps to target pair.
  Calibration directive injected into system prompt at inference time.
  Target never named to the subscriber. The machine calibrates. It does not announce.
