CHANGES DETAIL
--------------------------------------------------------------------------------

BUG FIX 1 — Tab switching without reload
  Root cause: useState + useEffect for visited-tab tracking introduced a
  two-render gap. Route changed (render 1), useEffect fired post-paint adding
  tab to visited set (render 2). During that gap, TabPanel didn't exist in DOM.
  Fix: replaced async useState with synchronous useRef. Tab is added to
  visitedRef.current inline during render — no gap, no blank frame. Removed
  duplicate currentRoute declaration.

BUG FIX 2 — Memory buttons not responding after tab switch
  Root cause: queryClient.removeQueries() killed the cache but didn't trigger
  refetch for the still-mounted observer (persistent tabs keep MemoryWidget
  alive). shownQuestionId ref persisted across tab switches.
  Fix: changed to invalidateQueries() (marks stale, triggers refetch). Reset
  shownQuestionId.current = null before invalidation.

FEATURE 1 — Reward widget gating (rewardWidgets store)
  MicroGameWidget, MicroImageWidget, CosmicUpdateWidget, PlannerWidget now gated
  by milestone + weekly cooldown. Show once per week max, only when user has:
  3+ assembled SELF-ASSEMBLY modules, OR 3+ balanced CHAKRA-ENGINE chakras, OR
  20%+ overall assembly progress, OR any awakening/forming module (early users).
  Reduces CPU cost (MicroGameWidget runs 150ms game loop) and creates tangible
  reward for spiritual/system work.

FEATURE 2 — Widget perf tracking
  WidgetErrorBoundary now measures constructor-to-componentDidMount time per
  named section. Results exposed via window.__LOT_WIDGET_PERF__ object
  (DevTools accessible). Console warning for sections exceeding 50ms.

FEATURE 3 — QR code for USERSHIP public profiles
  ProfileQRCode component: 80×80 canvas, theme-responsive (accent fg, base bg),
  error correction level M. Uses qrcode library (15KB). Encodes
  https://lot-systems.com/u/{customUrl||userId}. Shown in two places:
  - Public profile page (/u/:username) — bottom, USERSHIP only
  - Settings → Public Profile — live preview with current theme colors
