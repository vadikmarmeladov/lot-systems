DESIGN RECORD — LOT® Mail Architecture
================================================================================

PRINCIPLE: Simplest possible. No new model, no new table. Rides DirectMessage.

COMMAND SYNTAX:
  /email to Hitomi hello there
  ✉️ to Hitomi hello there  (emoji variant)

FLOW:
  Log NoteEditor → detectNewTriggers → 'email-compose'
  → parseEmailCommand() extracts { to: 'Hitomi', message: 'hello there' }
  → useSendLotMail POST /api/lot-mail/send
  → server: lookup user by first name (case-insensitive)
  → server: DirectMessage.create()
  → server: sync.emit('direct_message', { receiverId, ... })
  → SSE handler routes as 'lot_mail' to receiver only
  → Sync.tsx sync.listen('lot_mail', ...) → setMailMessages
  → LOT Mail inbox renders above chat form in Sync tab

COHORT DATING INTEGRATION:
  CohortConnectWidget "Mail" button → goTo('logs')
  → injects /email to <firstName> into Log textarea via DOM
  → user completes message and trigger fires

LOG RECORD:
  Sent mail appears in Log as lot_mail_sent event → MAIL: block
  Trigger status inline in NoteEditor → MAIL: block (live)

SERVER ENDPOINTS:
  GET  /api/lot-mail/inbox         → received messages, max 30
  POST /api/lot-mail/lookup        → find user by first name
  POST /api/lot-mail/send          → resolve name + send DirectMessage
