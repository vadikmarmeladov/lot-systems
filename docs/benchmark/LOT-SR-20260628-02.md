## ENGINEERING ACTIONS

### 1. Military Alert System

Added `[SCHEDULE][ACTIVE]` and `[SCHEDULE][STANDBY]` log entries that fire automatically when:

- **T-0 (Today):** `[SCHEDULE][ACTIVE] OP TODAY — {TYPE}: {text} | {date} | STATUS: EXECUTE`
- **T-24H (Tomorrow):** `[SCHEDULE][STANDBY] T-24H NOTICE — {TYPE}: {text} | {date} | STATUS: STANDBY`

**Deduplication strategy:** localStorage key `lot_cal_alerts` stores `{ date: "YYYY-MM-DD", fired: { key: true } }`. Record resets automatically on day rollover (midnight check via `tick`). Each event-day pair fires exactly once per calendar day, surviving page reloads.

### 2. Live Time Tracking

Added `tick` state (increments every 60 seconds via `setInterval`). This propagates through:
- `today` memo — recomputes at midnight, keeping date comparisons accurate
- `upcomingEntries` memo — re-filters when day rolls over
- `todayEntries` memo — re-checks at each tick
- Alert `useEffect` — re-runs at midnight, fires T-0 alert when event date becomes today

### 3. Countdown Labels — Upcoming Entries List

Replaced simple `dddd, MMMM D, YYYY` date display with a `[COUNTDOWN] date text` layout:

```
[TODAY]  Sun, Jun 28   Doctor appointment
[T-1D]   Mon, Jun 29   Team standup
[T-3D]   Wed, Jul 1    Quarterly review
[T-1W]   Sun, Jul 5    Family dinner
[T-2M]   Mon, Aug 28   Conference
```

`getCountdown()` function maps days remaining → `TODAY / T-1D / T-XD / T-1W / T-XW / T-XM`

### 4. Today-Events Alert Strip

When any calendar entry falls on the current date, a compact monospace alert strip renders above the upcoming list:

```
[TODAY] TASK: Doctor appointment
[TODAY] CALL: John re: Q3 budget
```

Uses `font-mono text-xs tracking-wide text-acc` — high-contrast, minimal footprint.

### 5. Structural Cleanup

- Merged redundant today/weeks state — `today` now comes from memo with `tick` dependency
- Consolidated `handleAddEntry` formatting
- Removed unused `blockView` prop pattern inconsistency

## LOG NOTIFICATION FORMAT

Alert entries written to Log stream use `event: 'calendar_alert'` (distinct from `'calendar_entry'`), keeping them filterable. Text format:

```
[SCHEDULE][ACTIVE] OP TODAY — TASK: Meeting with client | 2026-06-28 | STATUS: EXECUTE
[SCHEDULE][STANDBY] T-24H NOTICE — NOTE: Submit report | Mon, Jun 29 | STATUS: STANDBY
```

Metadata structure:
```json
{ "alertType": "today|tomorrow", "date": "YYYY-MM-DD", "text": "...", "type": "note|task|call" }
```
