05 // WHAT SHIPPED
--------------------------------------------------------------------------------
COMPOSE    `/email to <Name> <message>` typed anywhere in a Log entry (e.g.
           `/email to Hitomi hello!`) is detected by the existing Log-trigger
           scanner (same mechanism as /qi, /story, /prayer) as a new
           'lot-email' trigger. On fire: parses recipient + body, resolves
           the name against the sender's live cohort matches (case-
           insensitive first-name match), and sends via the pre-existing
           useSendDirectMessage() -> POST /api/direct-messages. Result
           renders inline under the editor as a new EMAIL: block (same
           all-caps LABEL/VALUE convention as PHYS:/SIL:/FREEZE:). No
           cohort match -> shows up to 5 available cohort first names
           instead of failing silently. /system help updated with the new
           command line.
DELIVER    No new wire protocol — reused POST /api/direct-messages verbatim
           (src/server/routes/api.ts ~3974-4086), which already: creates the
           DirectMessage row, emits SSE `direct_message` via the `sync`
           emitter, and auto-logs a `direct_message_sent` Log entry. Zero
           server or migration changes.
SYNC       Sync.tsx now listens for the (pre-existing, previously unused by
           any client surface outside DirectMessageThread) `direct_message`
           SSE event, filtered to the current user as sender or receiver,
           and renders live hits as a "✉️ LOT Email" section beneath the
           public chat feed — reusing the existing MessageTimeLabel
           sub-component. Kept as a separate section (not merged into the
           chat timeline) to avoid touching the chat message like/click
           logic — smallest correct change for "simplest."
COMMUNITY  "Cohort Dating through LOT Community" maps onto the existing
           cohort-matching system (GET /api/cohorts, CohortConnectWidget.tsx
           — labelled "Cohort:" in-app); there is no separate literal dating
           feature in this codebase. LOT Email's recipient resolution reuses
           that same match set, so composing "/email to <cohort member>"
           is the "Cohort Dating" entry point the task asked to incorporate.
