## FUNCTIONAL DESCRIPTION

### Time Tracking
- Widget maintains a live `now` Dayjs value ticking every 60 seconds.
- Today entries with a set time display a live countdown: `T-2h30m`, `T-45m`, `NOW`.
- All entries sorted by date then time within same date.

### Urgency Zones
```
OVERDUE     → any entry with date < today
TODAY       → date === today  (prominent, live countdown)
TOMORROW    → date === tomorrow
THIS WEEK   → tomorrow < date ≤ today+7
LATER       → date > today+7 (capped at 5 visible + "+N more")
```

### Military-Grade Notifications
Three surfaces for `calendar_notification` events:

1. **Auto-fire** — saving an entry for today triggers a `[CAL ALERT] TODAY` log automatically (500ms delay to let `calendar_entry` land first).
2. **Manual alert** — `[!]` button on OVERDUE/TODAY rows fires alert on demand.
3. **Log rendering** — `CAL [ALERT]:` block in Logs panel shows urgency · type · priority + entry text + date/time.

### Priority System
P1 / P2 / P3 toggle in add form. Priority stored in `metadata.priority`. Rendered as subtle badge in both widget and log views.
