NAME:            LOT® Quantum Tile (COSMO® Hardware Division; supersedes the
                 unspecified "Quantum Cube" slot in CQGS-WHITE-PAPER-SNAPSHOT.md)
FORM:            2-part stainless steel, 40mm x 40mm, 5mm height target (v1
                 realistic: 8-10mm) — Face A mirror-polished (no electronics),
                 Face B satin with camera window, memory-LCD display window,
                 single "COPY" button.
COMPUTE:         ESP32-S3 + OV2640-class camera (presence/QR only, never
                 streams frames) + reflective memory LCD + Bosch BME680-class
                 env sensor + Qi wireless charging (no port) + LOT Charging
                 Puck accessory.
CORE LOOP:       QI-46/Memory Engine detects a moment -> LOT API Connector
                 pushes one short line to the device (rate-floored, 20min
                 minimum) -> user may press COPY -> POST creates a
                 models.Log "hardware_copy" entry -> appears in the user's
                 Log tab (Logs.tsx), same feed as every other OS log event.
MANUFACTURING:   PCBWay (PCBA, possible CNC consolidation) + CNC metal shop
                 for stainless enclosure. Phased: 5 (proto) -> 25 (pilot) ->
                 100 (production). Planning-level per-unit cost $70-120
                 (device + charging puck), $3-6k one-time NRE — all figures
                 explicitly marked as pre-quote estimates.
