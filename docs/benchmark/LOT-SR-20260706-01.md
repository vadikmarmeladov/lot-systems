FEATURE SHAPE (as delivered)
  Trigger:   /email to [Name] [msg]  (also: /mail, ✉️, ✉, 📧)
             detected by logTriggers.ts RULES, same additive pattern as
             /prayer, /story, /qi.
  Compose:   inline panel in Logs.tsx (Block "✉ MAIL:"), mirrors the
             /story and /qi inline-response pattern already established.
  Send:      POST /api/mail { toName, body, subject? } — resolves
             recipient by case-insensitive first/last name across all
             LOT Community members (Op.iLike on User.firstName/lastName).
             404 with hint "No user named X in LOT Community" on miss;
             400 on self-send.
  Storage:   LotMail model (lot_mails table) — fromUserId, toUserId,
             subject, body, read flag. Own migration, own model, no
             overlap with DirectMessage (existing 1:1 chat) or EmailCode
             (auth magic-link, unrelated).
  Delivery:  sync.emit('lot_mail', {...}) server-side, routed only to
             the recipient's own SSE connection (checked against
             req.user.id in the SSE handler switch) — same scoping
             pattern as settings_updated (Cross-Device Sync doctrine).
  Surface:   Sync tab gains a Chat | Mail GhostButton strip. Mail tab
             renders EmailInbox (list + expand-to-read + mark-read on
             open) with an unread-count badge, live-updated via the
             lot_mail SSE event without a page reload.
  Cohort tie-in: ChatCatalystWidget (the existing Cohort Connect surface,
             "Connect:" block) gains a secondary "✉ Mail" button next to
             its existing cohort-member action button. Clicking it jumps
             to Log with `/email to [cohort member name] ` pre-filled —
             this is the "Cohort Dating through LOT Community" tie-in:
             LOT's existing behavioral-cohort matching IS its community/
             connection surface; Mail rides on top of it rather than
             inventing a parallel "dating" system.
  Discovery: /system help list gained one line for /email.
