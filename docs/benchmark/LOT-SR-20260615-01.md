COMPONENT GRADES:
  Button.tsx           A   Render-isolated per subscription. GPU ::before hover.
                           Correct polymorphic A/button dispatch. No issues.
  Input.tsx            B→A Fixed: useCallback stale-dep bug in Select (see below).
  Layout.tsx           A   NavButton memoized. Correct store subscription split.
  Page.tsx             A   Minimal and correct. Single store read.
  Text.tsx             A   Clean primitives. No issues.
  Block.tsx            B→A Fixed: string concat replaced with cn() (see below).
  ToggleSection.tsx    C→A Fixed: hover opacity inverted, max-height animation jank (see below).
  WidgetErrorBoundary  B→A Fixed: inline styles → Tailwind (see below).
  Link.tsx             A   Clean. Auto rel=noreferrer on _blank. No issues.
  Clock.tsx            A   Correct cleanup. @ts-ignore is intentional (setInterval return type).

FIXES APPLIED THIS SESSION:

  FIX 1 — Input.tsx: Select.useCallback stale dependency
    Problem: [onChange, value] in deps array — value not used in callback body.
             Caused unnecessary callback recreation on every keystroke.
    Fix:     Changed to [onChange].
    File:    src/client/components/ui/Input.tsx:88

  FIX 2 — Block.tsx: String concatenation inside cn()
    Problem: className built via string + hoverClassName concatenation,
             bypassing cn() merge logic and risking class conflicts.
    Fix:     Replaced with cn('-ml-4 pl-4 pr-4 ...', hoverClassName).
    File:    src/client/components/ui/Block.tsx:130

  FIX 3 — ToggleSection.tsx: Inverted hover opacity + animation jank
    Problem A: hover:opacity-30 on toggle header button causes the label to
               fade TO 30% on hover — UX inversion. Should become MORE visible.
               Fixed to hover:opacity-60 (clear affordance without harshness).
    Problem B: max-h-[2000px] / max-h-0 CSS transition is a well-known anti-pattern.
               CSS transitions run the full 2000px range regardless of actual
               content height → animation feels slow/laggy on short content
               and can visually clip on content taller than 2000px.
    Fix B:     Replaced with grid-rows-[0fr]/grid-rows-[1fr] transition.
               This is the current browser-native technique for smooth
               height animations with no fixed ceiling and correct easing.
    Problem C: Inline style for span transform (display, width). Moved to Tailwind.
    File:    src/client/components/ui/ToggleSection.tsx

  FIX 4 — WidgetErrorBoundary.tsx: Inline styles on retry button
    Problem: style={{ background: 'none', border: 'none', ... }} bypasses
             Tailwind and is inconsistent with the rest of the design system.
    Fix:     Replaced with Tailwind: bg-transparent border-0 p-0 text-inherit font-[inherit].
    File:    src/client/components/ui/WidgetErrorBoundary.tsx:68
