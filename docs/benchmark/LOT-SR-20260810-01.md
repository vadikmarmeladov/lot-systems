                     shown for EXECUTE/ALERT rows.

                     per timed entry when it enters the 60-minute window,
                     auto-dismisses after 30s or on ACK click. Styled with the
                     same grid-fill-light + --base-color convention as
                     EvolutionMilestoneToast.tsx — no borrowed keyframe
                     dependency (dropped an implicit-coupling animation that
                     only existed because that other component happens to
                     inject it into document.head).

                     (today's own entries moved to the Today panel, so nothing
                     appears twice) with time shown inline where set.
