# COSMO® Cube — Quick Reference

## Model C1 · Hardware Documentation Set v1 · DRAFT

---

## What It Is

A two-part 316L stainless steel device, 40mm x 40mm, connected to
lot-systems.com over Wi-Fi. It receives ambient, one-line notifications
from the LOT AI, senses temperature/humidity/pressure/air quality, carries
a camera, and has one button.

---

## The Two Faces

### Top Face — Camera, Screen, Button

- Camera, off-center, with a hardware-wired privacy LED that is on
  whenever the sensor has power — not a software toggle.
- 1 inch square OLED display, blank at rest. Shows one line of text only
  when the LOT AI has something worth saying.
- Copy button. One press writes an entry to the Log tab on
  lot-systems.com. Local acknowledgment first, sync after.

### Bottom Face — Polished Stainless Steel

Mirror-polished, rests on a Qi wireless charging pad. A small ceramic
window over the coil lets charging power pass through the metal shell —
the rest of the face is unbroken polished steel.

---

## The One Rule

Every notification the Cube shows follows the same rule as the rest of
LOT(R): one line, no alarm, exact moment. It does not badge. It does not
buzz. It waits, and when it speaks, the moment was earned.
