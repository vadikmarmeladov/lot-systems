# COSMO® CIA — Firmware Technical Document v1.0

**Classification:** Internal — Firmware Engineering
**Platform:** ESP32-S3 / ESP-IDF v5.2 / FreeRTOS
**Target Device:** COSMO® CIA v1.0

---

## 1. Architecture Overview

The firmware follows a task-based concurrent model on FreeRTOS. Each subsystem is an independent task. Inter-task communication uses queues and FreeRTOS event groups. There is no blocking in interrupt context — all ISR work is deferred to handler tasks via queues.

```
                    ┌───────────────────┐
                    │   app_main()      │
                    │   Initialise HW   │
                    │   Start tasks     │
                    └─────────┬─────────┘
          ┌──────────┬────────┼────────┬──────────┬──────────┐
          ▼          ▼        ▼        ▼          ▼          ▼
    wifi_manager  https_  display_  sensor_   button_   ota_manager
    (priority 5) client  renderer  sampler   handler   (priority 1)
                 (pri 4)  (pri 3)  (pri 3)   (pri 6)
                              │
                         session_compress
                          (priority 1)
```

## 4. Peripheral Drivers

### 4.1 I²C Bus (SDA=3, SCL=4, 400kHz)
Devices on I²C:
- **SSD1306 OLED** — address 0x3C
- **BME688** — address 0x76 (SDO pulled low)

Driver uses ESP-IDF `i2c_master_*` API. Mutex-protected for concurrent access from display and sensor tasks.

### 4.2 SPI / QSPI (W25Q32 External Flash)
- Uses ESP-IDF `esp_flash_*` API on QSPI bus
- Configured as secondary flash partition via `partitions.csv`
- Session log ring buffer stored here
- 30-day capacity at typical usage

### 4.3 Camera DVP (OV2640)
- Uses `esp_camera` component (ESP32-S3 native support)
- XCLK: 20MHz generated by LEDC peripheral
- Capture resolution: QVGA (320×240) for thumbnails, SVGA (800×600) for stills
- Output format: JPEG at quality 80%
- Triggered by `camera_driver` task on queue message from `button_handler`

### 4.4 BME688 (I²C + BSEC2)
- Bosch BSEC2 library (pre-compiled static lib in `components/bsec2/`)
- Provides: temperature, humidity, pressure, IAQ (0–500 scale), CO₂-equivalent, VOC-equivalent
- IAQ accuracy 0–3: accuracy ≥ 2 required before uploading data
- Sample rate: LP (low power) mode — 1 reading per 3s in BSEC2, decimated to 1/min in session log

### 4.5 Battery ADC
- ADC1 Channel 5 (GPIO36) with 100kΩ/200kΩ voltage divider
- Range: 3.0V–4.2V → maps to 0%–100% with sigmoid approximation
- Sampled every 60 seconds, reported in all API calls
- Low battery threshold: 15% → show "🔋LOW" on display, increase poll interval to 300s

## 5. Boot Sequence

```c
void app_main(void) {
    // 1. NVS init — load config
    nvs_flash_init();
    config_load();          // SSID, API token, device_id

    // 2. Hardware init
    i2c_init();
    spi_flash_init();
    display_init();         // Show boot logo
    bme688_init();
    camera_init();
    button_init();          // Configure IRQ
    battery_adc_init();

    // 3. Start tasks
    xTaskCreatePinnedToCore(wifi_manager_task, ...);
    xTaskCreatePinnedToCore(https_client_task, ...);
    xTaskCreatePinnedToCore(display_renderer_task, ...);
    xTaskCreatePinnedToCore(sensor_sampler_task, ...);
    xTaskCreatePinnedToCore(button_handler_task, ...);
    xTaskCreatePinnedToCore(ota_manager_task, ...);
    xTaskCreatePinnedToCore(session_compress_task, ...);

    // 4. Delete self — tasks handle everything
    vTaskDelete(NULL);
}
```

If `config_load()` returns `ESP_ERR_NVS_NOT_FOUND`, the device enters BLE provisioning mode before starting the main task set.

## 6. Wi-Fi Manager

States: `DISCONNECTED → CONNECTING → CONNECTED → RECONNECTING`

- On `CONNECTED`: posts event to `https_client` task via event group
- On disconnect: waits 5s, retries; after 3 failures, enters 60s backoff
- Maximum backoff: 10 minutes
- WPA2-Personal only for v1.0; WPA3 in v1.1
- NTP sync on first connection: `pool.ntp.org`

## 7. HTTPS Client (LOT API)

Polls every 60 seconds when Wi-Fi connected:

```c
void https_client_task(void *arg) {
    while (1) {
        wait_for_wifi_connected();

        // 1. Device ping every 6 hours
        if (should_ping()) {
            lot_api_ping();
        }

        // 2. Fetch notifications
        lot_notification_t notifs[8];
        int count = lot_api_get_notifications(notifs, 8);
        for (int i = 0; i < count; i++) {
            notification_queue_push(&notifs[i]);
        }

        vTaskDelay(pdMS_TO_TICKS(60000));
    }
}
```

TLS configuration:
- CA cert: ISRG Root X1 (Let's Encrypt) bundled in firmware
- Verify CN: `lot-systems.com`
- TLS 1.3 preferred, TLS 1.2 fallback
- Certificate pinning: optional, disabled in v1.0 for update flexibility

## 8. Notification Renderer

Display state machine:

```
IDLE → NOTIFICATION_INCOMING → DISPLAYING → ACKNOWLEDGED → IDLE
                                    ↑
                              (scrolling text loop)
```

- Notification text > 16 chars: horizontal scroll at 2 char/s
- Multiple pending: cycle through with 3s per notification
- Copy button press: send `ACTION_COPY` to `https_client` queue, advance to next

## 9. Button FSM

```
State: IDLE
  │ falling edge (press)
  ▼
State: PRESSED
  │ release < 500ms        → ACTION_SINGLE_PRESS (Copy)
  │ hold 500ms–3000ms      → ACTION_DOUBLE_CHECK (wait for 2nd press)
  │ hold 3000ms–10000ms    → ACTION_LONG_HOLD (provisioning mode)
  │ hold > 10000ms         → ACTION_FACTORY_RESET
```

Debounce: 20ms hardware RC + 50ms software confirmation window.

## 10. Session Compression

Runs daily at 03:00 local time (NTP-derived):

```c
typedef struct __attribute__((packed)) {
    uint32_t date_unix;
    uint16_t notifs_received;
    uint16_t notifs_acknowledged;
    float avg_response_sec;
    bsec_sample_t sensor_samples[24];   // hourly snapshots
    button_event_t button_events[128];  // ring-limited
    uint8_t battery_profile[24];        // % per hour
    uint16_t firmware_version;
    uint32_t uptime_seconds;
} session_record_t;

// Compress + upload
uint8_t compressed[2048];
int compressed_size = LZ4_compress_HC(
    (char*)&session, compressed, sizeof(session), sizeof(compressed), 9
);
lot_api_upload_session(compressed, compressed_size);
```

## 11. OTA Update

```c
void ota_manager_task(void *arg) {
    while (1) {
        // Check once daily
        vTaskDelay(pdMS_TO_TICKS(86400000));

        lot_firmware_info_t info;
        if (lot_api_check_ota(&info) && info.version > FIRMWARE_VERSION) {
            esp_https_ota_config_t ota_config = {
                .http_config = {
                    .url = info.url,
                    .cert_pem = LOT_CA_CERT,
                }
            };
            esp_err_t ret = esp_https_ota(&ota_config);
            if (ret == ESP_OK) {
                esp_restart();  // boots new firmware
            }
        }
    }
}
```

Rollback: if new firmware fails to set `esp_ota_mark_app_valid_cancel_rollback()` within 60s of boot, ESP-IDF automatically rolls back to previous partition.

## 13. Error Codes

| Code | Constant | Description |
|------|----------|-------------|
| 0x01 | `ERR_WIFI_TIMEOUT` | Wi-Fi did not connect in 30s |
| 0x02 | `ERR_API_UNREACHABLE` | HTTPS connection failed |
| 0x03 | `ERR_API_AUTH` | 401 from LOT API — token invalid |
| 0x04 | `ERR_SENSOR_INIT` | BME688 I²C not responding |
| 0x05 | `ERR_DISPLAY_INIT` | SSD1306 I²C not responding |
| 0x06 | `ERR_CAMERA_INIT` | OV2640 DVP not responding |
| 0x07 | `ERR_FLASH_INIT` | W25Q32 QSPI not responding |
| 0x08 | `ERR_OTA_VERIFY` | SHA-256 mismatch on OTA image |
| 0x09 | `ERR_BATT_LOW` | Battery < 5%, shutting down |
| 0xFF | `ERR_FATAL` | Unhandled exception — reboot in 5s |

Errors display briefly on OLED as: `ERR 0x02` with icon, then device retries or sleeps.

## 14. Build Instructions

### Requirements
- ESP-IDF v5.2 (`git clone --recursive https://github.com/espressif/esp-idf.git -b v5.2`)
- Python 3.11+
- USB-UART bridge (e.g., CH340G) for factory flashing

### Build
```bash
cd firmware/
idf.py set-target esp32s3
idf.py menuconfig          # set Wi-Fi/API defaults if needed
idf.py build
```

### Flash (factory)
```bash
idf.py -p /dev/ttyUSB0 flash monitor
```
