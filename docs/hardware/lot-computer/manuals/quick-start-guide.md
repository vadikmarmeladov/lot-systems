# LOT Computer — Quick Start Guide

*(Concept-stage manual — written ahead of hardware, to be revised against a
real production unit before Phase 4 launch.)*

## In the box

- 1× LOT Computer (the puck)
- 1× Qi wireless charging dock
- 1× USB-C cable

## 1. Charge it

Place the puck, polished side down, on the charging dock. A small glyph
appears on screen if the puck is already awake; otherwise it simply charges
in the background. Give it a full charge before first use.

## 2. Pair it

1. On lot-systems.com, open **Settings → Devices → Add a device**.
2. The puck's screen shows a short pairing code.
3. Enter that code on the Settings page.
4. Done — the puck is now tied to your account.

## 3. Place it

Put it somewhere you'll actually glance at — a desk, a nightstand. It has one
screen and one job: show you the occasional right-moment nudge from your
Memory Engine.

## 4. Use the button

- **Short press** = **Copy**. Whatever's on screen right now gets written
  into your Log tab, instantly.
- **Long press** = take a photo, attached to that same Log entry. The camera
  only ever activates on this explicit gesture — never on its own, always
  with its indicator light on when it does.

## 5. That's it

No app to install. No account separate from lot-systems.com. It just sits
there and, once in a while, says the right thing.
