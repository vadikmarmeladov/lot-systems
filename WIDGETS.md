## Core Widgets

### Time Widget

The clock and stopwatch at the heart of every session. Displays the current time with toggleable 12/24-hour format and an optional hourly chime that plays at the top of each hour.

- **Data Source:** Local system clock via the `dayjs` library
- **Persistence:** Format and chime preferences stored in `localStorage` via nanostores
- **Connection:** Global state management through nanostores; integrates with the system sound layer for chime playback

### Memory Widget

The primary self-reflection engine. Surfaces psychological and behavioral questions generated by the server. Users respond through button-based answer options. Tracks answered questions per session and displays stoic reflections between rounds. Triggers badge unlock notifications when milestones are reached.

- **Data Source:** `/api/memory` endpoint for question generation; `/api/logs` for recording answers
- **Persistence:** `localStorage` for session tracking and recent question history
- **Connection:** Deeply integrated with the badge system, log context, and Quantum Intention Engine. Badge unlocks trigger milestone toasts. Answer signals feed into pattern recognition

### Planner Widget

A four-dimensional daily planning interface organized around Intent, Today, How, and Feeling. Features a spreadsheet-like layout with full keyboard navigation (arrow keys). Each plan entry is recorded as a signal for downstream pattern analysis.

- **Data Source:** `plannerWidget` nanostore for state and values; `/api/logs` endpoint for plan persistence
- **Connection:** Records `plan_set` signals to the Quantum Intention Engine; integrates with the log-based activity tracking system

### Recipe Widget

Suggests meals based on time of day — breakfast (5–9 AM), lunch (11 AM–2 PM), dinner (5–8 PM), and snacks (2–5 PM). Automatically logs the recipe when viewed on the System tab and displays a farewell phrase on dismissal.

- **Data Source:** `recipeWidget` nanostore for visibility, recipe content, and meal time
- **Persistence:** Activity logged to `/api/logs`
- **Connection:** Tied to System tab visibility; uses Quantum Intention Engine signals for timing optimization

## Biofield & Evolution Widgets

### Energy Capacitor (Biofield Capacitor)

Tracks personal energy (ATP) with biofield emission status. Cycles through four views: Overview, Correlation, Romantic, and Needs. Forecasts burnout risk and displays mood-to-energy correlation over time.

- **Data Source:** `/api/energy` endpoint; log context for mood correlation analysis
- **Connection:** Records `energy_*` signals; cross-references mood entries for biofeedback loop visualization

### Emotional Check-In

A biofield check-in with 14 emotional states to choose from. Cycles through Prompt, History, Patterns, and Graph views. Shows 30-day emotional history. Conditionally appears during morning (6–12) and evening (17–22) windows with a 3-hour cooldown between sessions.

- **Data Source:** `/api/emotional-checkins` endpoint for mood history; `/api/logs` for cooldown tracking
- **Connection:** Part of the conditional System.tsx widget stack; contributes to overall biofield analysis

### Evolution Widget (Citizen Index)

Displays the CQGS Citizen Index — a progression level derived from activity, achievements, and consistency. Cycles between a metrics view (level, achievements, streak) and an activity breakdown view (events by type).

- **Data Source:** `/api/narrative` endpoint; log data for entries, active days, and streak calculation
- **Persistence:** `localStorage` for stat snapshots
- **Connection:** Integrates with the evolution system, narrative progression, and log-based streak engine

### Interface Evolution Widget

Shows the full CQGS evolution state across seven dimensions: Exploration, Consistency, Depth, Connection, Intimacy, Care, and Courage. Cycles through Dimensions, Features, and Effects views.

- **Data Source:** Nanostores (`$evolutionState`, `$featureUnlocks`, `$visualEffects`)
- **Connection:** Syncs with the evolution progression system; references log context for biofeedback metrics. Feature unlocks activate as evolution dimensions increase

### Evolution Milestone Toast

A notification overlay that appears when evolution milestones or feature unlocks occur. Auto-dismisses after 6 seconds.

- **Data Source:** `localStorage` for milestone tracking; nanostores (`$featureUnlocks`)
- **Connection:** Triggered by the evolution system's unlock events

### Narrative Widget

An RPG-style story progression engine grounded in actual user activity data. Cycles through Story, Achievements, Quests, and Context views. The narrative tone adjusts based on engagement level.

- **Data Source:** `/api/narrative` endpoint for arc and achievement data; `/api/logs` for engagement-aware narrative generation
- **Connection:** Syncs with the evolution system; log-derived engagement level directly affects narrative content and tone

### Goal Journey Widget

Detects and tracks personal goals through journey stages. Cycles through Journey, Goals, and Path views. Displays the primary goal, active goal count, and progression narrative.

- **Data Source:** `/api/goal-progression` endpoint
- **Connection:** Records `goals_viewed` signals with active goal count; integrates with the narrative system

Prompts users to connect with cohort members who share similar patterns. Shows suggested connections as opportunities for meaningful interaction. Cycles through multiple catalyst prompts.

- **Data Source:** `/api/chat-catalysts` endpoint; user store for permission verification
- **Connection:** Records `connection_accepted` signals; navigates to user profiles or community chat on acceptance

### Pattern Insights Widget

A pattern compiler that surfaces discovered behavioral patterns and cohort matches. Cycles through Patterns, Cohort, and Evolution views. Shows pattern delta across multiple time windows.

- **Data Source:** `/api/patterns`, `/api/cohorts`, and `/api/pattern-evolution` endpoints
- **Connection:** Records `pattern_checkin` / `reflect` / `integrate` signals; links to matching user profiles

Browse and connect with the top 5 most similar cohort members by match percentage. Expandable member cards reveal shared pattern lists.

### Intentions Widget

Monthly intention setting and tracking system. Cycles through Set, Current, Alignment, and Reflection views. Displays intention progress alongside widget diversity and behavioral alignment metrics.

- **Data Source:** `localStorage` for current intention; log context for activity alignment analysis; Quantum Intention Engine signals
- **Connection:** Records `intention_set` / `integrate` signals; references log context for alignment scoring

### Self-Care Moments

Surfaces self-care suggestions during key times of day (10 AM–12 PM, 2–5 PM, 7–10 PM) or when the Quantum Intention Engine detects anxiety or overwhelm patterns. Limited to 3 appearances per day with a 3-hour cooldown.

- **Data Source:** Quantum Intention Engine analysis; `localStorage` for cooldown and session tracking
- **Connection:** Conditionally displayed in System.tsx; gated by both time-of-day and pattern detection logic

### Awareness Dashboard

A clickable, cycling display of the user's psychological profile. Shows self-awareness percentage, archetype, values, emotional patterns, dominant needs, sentiment breakdown, and introspection depth.

- **Data Source:** `/api/profile` endpoint via the `useProfile` hook
- **Connection:** Displays profile-derived awareness metrics; integrated into the System.tsx layout

Real-time system heartbeat metrics with 1-second polling. Displays events per minute, quantum flux, neural activity, and resonance (Hz). Cycles through Metrics, Activity, and User Load views.

- **Data Source:** `/api/system/pulse` endpoint (polled every second); log context for comparison
- **Connection:** Provides live system telemetry; cross-references with log context for anomaly detection

## Architecture Overview

### Dashboard Orchestration

All widgets are orchestrated by `System.tsx`, the master dashboard component. Widgets are organized into logical stacks:

1. **Header** — User identity, week number, date, location
2. **Community Pulse** — Convergence atmosphere with narrative
3. **Tags & Team** — User affiliations and team display
4. **Time & Environment** — Clock, quantum random, weather, astrology/psychology cycling
5. **Context Stack** — Contextual prompts, chat catalysts, interventions
6. **Bioethics Stack** — Energy, narrative, evolution, interface evolution, milestones
7. **Settings** — Mirror, sound/radio toggle, breathe mode
8. **Lifestyle Stack** — Recipes, emotional check-in, self-care
9. **Intentions & Planning** — Intentions, planner, memory, micro tools
10. **Subscriber Stack** — Cosmic update, quantum sign
11. **Quantum Engine Connect** — Car, home, computer connection toggles
12. **QIE Stack** — Quantum state, pattern recognition, feedback, signal stream
12. **Dashboard Stack** — User metrics, system progress, system pulse
13. **Stats Stack** — Patterns, consciousness, wellness, memory stats, growth, badges

### Core Data Systems

| System | Role | Key Endpoints |
|--------|------|---------------|
| **Quantum Intention Engine (QIE)** | Central intelligence — analyzes signals, detects patterns, recommends actions | Nanostore-based; client-side signal processing |
| **Log Context** | Foundation data layer — aggregates all interactions | `/api/logs` |
| **Evolution System** | Progression tracking across 7 dimensions | `/api/narrative`, nanostores |
| **Badge System** | Milestone gamification | `/api/badge-stats`, `localStorage` |
| **Narrative System** | RPG-style story grounded in engagement | `/api/narrative` |
| **Profile System** | Psychological profiling and awareness | `/api/profile` |

### State Management

- **Nanostores** — Global reactive state for cross-widget communication (user, weather, theme, online counts, sound, settings, evolution, signals)
- **localStorage** — Persistent preferences, cooldowns, session tracking, and mode flags
- **Server endpoints** — Dynamic data via REST API with React Query caching

### Visibility Logic

Widgets use a layered visibility system:
- **Time-gated** — Recipes (meal times), emotional check-in (morning/evening), self-care (key hours)
- **Cooldown-gated** — Emotional check-in (3h), self-care (3h, max 3/day), intentions (2–3 day), subscribe (10 days)
- **Activity-gated** — Subscribe (10+ memory answers), quantum sign (low activity users)
- **Subscription-gated** — Cosmic update, quantum sign (Usership/R&D/Legacy tags)
- **Mode-gated** — Investor widgets (`lot-investor-mode`), flash drive (offline or investor)
- **Pattern-gated** — Self-care (anxiety/overwhelm detected), intentions (seeking-direction pattern)
